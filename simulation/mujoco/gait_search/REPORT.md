# 새 STEP 보행 최적화 결과 — 2026-09-08

현재 추정 물리 모델에서 검증한 후보 중 선택한 보행이다. 전역 최적성이나 실물 성능을 보장하지 않는다. 이 탐색 단계에서는 실제 로봇 통신·설치·펌웨어 변경을 하지 않았다. 이후 전체 업데이트에서 동일 궤적을 공용 C 정책으로 이식해 V13의 `trot5`와 앱의 개선 전진 버튼에 추가했다. 실기 보행 검증은 별개이며 아직 수행하지 않았다.

## 실행과 UI

```bash
conda activate spot_omg
mjpython simulation/mujoco/gait_lab.py
```

- **R**: 같은 창에서 물리 상태·보행 위상·모터 지연 이력을 모두 초기화하고 재시작.
- **1**: 기존 공용 C drive 정책, 최대 전진 입력 1.0.
- **2**: 선택한 개선 보행. 기본 선택.
- **P / Space**: 일시정지·재개.
- 각 재생은 정지 준비 3초 + 보행 30초. 종료 후 R로 다시 재생한다. 화면에 시간·거리·속도·자세를 표시한다.

## 선택 과정

초기 궤적 160개와 위치·속도·가속도가 이어지는 C2 발 궤적 160개, 총 320개를 탐색했다. 초기 탐색의 전원은 12.5V였고, 사용자의 11.1V 3S 확인 후 기준 전압을 11.1V로 변경해 후보를 다시 선택했다. 11.1V는 명목전압을 기준 운전점으로 사용한 것이며 현재 배터리 전압을 측정한 값은 아니다.

발의 전후 이동·들림 궤적을 역기구학으로 J2/J3 각도로 바꾸고 대각 다리 위상을 반 주기 차이로 배치한다. 후보 간 물리 파라미터나 모터 이득을 최적화하지 않았으며 같은 토크 제한·접촉 모델을 사용했다. 기존 정책과 동일한 모터 제어 경로로 힘을 적용한다.

낙상·몸체 지면 접촉을 거부하고 전진 속도에서 옆방향 이탈·방향 오차·자세 흔들림·미끄러짐·정격 토크 초과·포화·거리당 기계적 에너지 비용을 감점했다. 상위 후보와 모터 부담이 낮은 후보를 네 가지 20초 조건으로 평가한 뒤, 모든 조건의 자세 유지 여부와 최악 점수 60% + 평균 점수 40%로 선택했다.

초기 정지 준비 후 보행 첫 2초는 정상상태 속도·에너지 통계에서 제외했다. 정격 초과 비율은 각 관절·샘플이 정격 토크를 넘는 비율이며 실제 열·온도를 의미하지 않는다.

## 20초 조건별 비교

| 조건 | 기존 속도 m/s | 개선 속도 m/s | 개선 최대 기울기 | 개선 최종 방향 오차 |
|---|---:|---:|---:|---:|
| 11.1V 기준 | 0.028 | 0.189 | 3.7° | 1.4° |
| 질량 +20% (배터리 제외), 마찰 0.55, 10.8V | 0.027 | 0.184 | 3.2° | 3.9° |
| 질량 −15% (배터리 제외), 마찰 1.05, 12.6V | 0.031 | 0.187 | 4.2° | 0.5° |
| 배터리 중심 이동, 지연 40ms | 0.025 | 0.183 | 3.9° | 6.6° |

기준 조건에서는 속도 6.7배. 무게·이동 거리로 정규화한 절대 관절 기계적 일(COT)은 1.05 → 0.85. **정격 토크 초과 비율은 16.4% → 28.1%로 증가**하므로 모든 면에서 우월한 보행은 아니다. 발열과 지속 운전 안전성은 검증하지 않았다.

## 선택 후 별도 검증

| 조건 | 기존 속도 m/s | 개선 속도 m/s | 개선 결과 |
|---|---:|---:|---|
| nominal_60s | 0.028 | 0.189 | 자세 유지 |
| fine_step | 0.028 | 0.198 | 자세 유지 |
| low_friction | 0.036 | 0.191 | 자세 유지 |
| lateral_push | 0.028 | 0.186 | 자세 유지 |
| motor_loss | 0.025 | 0.174 | 자세 유지 |

`nominal_60s`: 60초. `fine_step`: 1ms 적분. `low_friction`: 마찰 0.4. `lateral_push`: 몸체에 횡방향 8N을 0.15초 적용. `motor_loss`: 토크·무부하 속도 15% 감소 및 지연 40ms. 추가 조건에서는 후보를 다시 선택하지 않았다.

## 선택한 파라미터

```json
{
  "period": 0.8436922561509421,
  "duty": 0.5979488437760033,
  "stride": 0.06280689761866355,
  "lift": 0.012,
  "height": 0.20175228283900074,
  "forward_offset": -0.035,
  "spread": 0.7411947428343884
}
```

길이 단위는 m, 주기는 초, spread는 도. duty는 한 다리의 계획된 지지 비율이다. 실제 접촉과 일치한다고 강제하지 않는다. 몸체 높이·관절 영점·링크 길이 및 충돌 형상은 현재 CAD 기반 근사에 종속된다.

## 재현과 제한

```bash
# 기존 search_v1.json 시드를 사용한 C2 탐색 재현
python simulation/mujoco/optimize_cad_gait.py --trials 160 --seed 73 --source-voltage 12.5
# 현재 11.1V 기준 후보 선택
python simulation/mujoco/validate_cad_gait.py
python simulation/mujoco/check_gait_holdouts.py
```

탐색 기록은 search_v1.json / search.json, 20초 비교는 validation.json, 확정 후보는 selected.json, 추가 검증은 holdouts.json이다. 물리 조건도 결과에 보관했다. 재실행 시 해당 결과 파일을 갱신한다.

총질량 4.398kg 및 질량 배분·마찰·전압 강하·모터 제어는 추정값이다. CAD 축과 영점도 실물 보정 전이다. PLA/PETG는 강체이며 변형·백래시·모터 과열·보호회로는 포함하지 않는다. 따라서 이 결과는 시뮬레이터 후보 선정이며 실물에 그대로 적용 가능한 최종 정책이라고 주장하지 않는다.
