# 제자리 회전 중심 이동 실험 — 2026-09-12

## 결론

제자리 회전은 아직 합격하지 않았다. 회전 중 몸체 중심 이동을 줄이는 후보는 얻었지만, 시작 자세 전환의 이동과 앞발 들림 부족이 남았다. 기존 정책을 교체하지 않았으며 앱·실물 펌웨어에 배포하지 않았다.

기존 영상은 카메라가 몸체 yaw를 따라가므로 회전이 옆걸음처럼 보이는 문제가 있었다. 하지만 물리 모델에서도 실제 중심 이동이 확인됐다. 새 영상은 지면에 고정한 사선·상면 카메라와 50mm 격자, 초기 중심 기준 반지름 20mm 원을 사용한다. 시각 표시만 추가하며 몸체를 고정하거나 물리 접촉을 변경하지 않는다.

## 측정과 후보

중심은 freejoint 원점 대신 CAD 몸통 `cad_base.xipos`로 정의했다. 위치와 실제 접촉력은 평가에만 사용한다.

- 기존 `measured_front_lift`: 27초 시험의 정상 회전 구간 중심 최대 이동은 좌 110mm, 우 105mm였다.
- 비교 후보 `inside_60_4`: 기존 `measured_lift`의 발 궤적을 CAD 발 위치로 변환해 회전 중심을 보정하고, 안쪽 앞발 목표를 4mm 높였다. 앞발 높이 강화 정책과 동일한 발 들림을 달성한 후보는 아니다.
- 후보의 정확한 설정: `artifacts/audits/pivot-center-2026-09-12/preview-profiles.json`. 이름은 **몸체 중심 회전 보정 · 실험 (검증실패)**이다.

후보는 방향마다 총 67초를 실행했다. 2초에 회전 시작, 5~65초를 정상 회전 60초로 평가하고 65초에 Stop을 요청했다.

시작 직후 약 5cm 앞으로 옮겨가는 자세 전환이 있다. 정상 구간의 작은 순변위만으로 제자리 회전 성공이라고 판단하면 안 된다. 앞발 15mm 들림 목표도 실패했다. 기존 앞발 강화 정책보다 들림이 악화됐으므로 대체 정책으로 승격하지 않는다. 원본은 `long-validation.json`과 방향별 CSV에 보존했다. 기존 정책과 장기 후보의 시험 길이가 다르므로 위 수치는 같은 시간의 정량 A/B 비교로 취급하지 않는다. 영상은 양쪽을 동일한 시간·명령으로 재실행한다.

## 실패한 접근도 보존

- 공통 회전 중심을 기준으로 한 강체 원호 IK: 목표 기하는 맞지만 실제 회전은 약 5~10°/s에 그쳤고 중심 이동도 커졌다.
- 시작 발 위치를 그대로 유지하는 보정: 정상 회전 이동이 140~195mm로 악화됐다.
- 세 발 지지 원호 회전: 일부 후보가 기울기 정지했으며 정지하지 않은 후보도 약 3.7°/s로 느렸다. 채택하지 않는다.
- 지연된 IMU와 관절 위치, 예정 지지 단계로 중심 이동을 추정하는 `PivotHold`: 실제 접촉을 가정하므로 미끄러짐을 완전히 관측할 수 없다. 27초 시험에서 시작점 기준 최대 이동 약 38~48mm가 남았다. 실물 적용하지 않는다.

검색 결과는 각각 `search.json`, `entry-search.json`, `crawl-search.json`, `hold-search.json`, `hold-audit.json`에 있다. 검색기가 고른 최소 점수는 합격을 뜻하지 않는다. 영상용 설정은 검색기의 마지막 출력과 분리했다.

## 검증 수준과 한계

- 호스트 검사: CAD IK, 지지 궤적, 보정 범위·연속성, 관측 누락 처리, 서보 변환 관련 테스트 20개 통과.
- 물리 시뮬레이션: 후보별 실제 동역학 실행 및 60초 정상 회전, Stop 확인. 토크·속도 제한과 쿠션 형상은 유지했다.
- 실기 설정 readback·실제 위치 유지·전체 동작 시험: 이번 변경에는 수행하지 않았다.
- 과거 실측 로그의 관절별 표본 간격은 약 240ms다. 정확한 모터 지연을 식별한 데이터가 아니다. 질량·접촉·동특성에는 추정값이 남아 있다.
- `PivotHold`의 인코더 채널은 현재 시뮬레이터의 40ms 벡터 지연이며 실제 순차 240ms 수집을 재현하지 않는다. 실기 재현 검증이 완료됐다고 해석하면 안 된다.

다음 해결 대상은 시작 자세의 하중 이동과 안쪽 앞발의 실제 이륙이다. 정상 회전 중심 보정만으로 이 문제를 해결했다고 표현하지 않는다.
