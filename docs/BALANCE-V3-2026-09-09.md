# 고속 전진 흔들림 및 앱 안전 정지 수정

2026-09-09, 가상 로봇 `balance-v3-sim`, iOS V0.3.3 (9) Debug.

## 수정

- 보행/자세 전환 중 P=0.10, I=0.03, D=0으로 변경했다. 지연·양자화된 각도의 미분 보정이 최대 속도에서 진동을 키운 문제를 제거한다. 정지 시 기존 P=0.25/I=0.15/D=0.015와 수평 보정을 유지한다. 보정량·속도·적분 포화 제한도 유지한다.
- 크루즈 전진/후진 입력 범위는 ±1000을 유지한다. 빠른 트롯과 하이 스텝은 장시간 최대 후진에서 지지를 잃어 후진만 -600으로 제한한다. 전진은 1000이다. `reverse_limit`으로 보고하고 앱 정책 설명에도 명시한다.
- 앱은 기울기/IMU 안전 정지 시 즉시 안전 상태를 반영하고 재출발을 잠근다. 스틱 해제 및 명시적 Recover 후 정상 상태 확인이 필요하다. 지연된 정상 snapshot만으로 잠금이 풀리지 않는다.
- 예기치 않은 정지 뒤 같은 터치의 업데이트를 새 보행으로 처리하지 않는다. 이미 stopping 중에 도착한 거부 응답도 완료 처리하여 5초 시간 초과에 갇히지 않는다.
- 가상 로봇은 이미 멈춘 상태에서 새 @S를 받으면 `reason=already-stopped` 응답을 보낸다. 안전 잠금은 해제하지 않는다.
- 런타임은 최근 30초의 입력·센서·물리 자세·보정·전압을 메모리 순환 기록한다. 안전 상태가 정상에서 오류로 바뀌면 `/private/tmp/spot-omg-sim/incident-*.json`으로 저장한다. `imudiag`의 `last_incident`로 파일을 확인한다.

## 검증

- Python 전체 253개 및 26개 subtest 통과.
- iOS 40개 테스트 통과. 특히 기울기 정지 후 터치 유지, 명시적 복구 전 재출발 차단, stopping 중 거부 응답, watchdog 후 스틱 해제를 검증했다.
- 60초 구동 + 8초 정지 관찰 **29조건** 통과: 다섯 정책의 최대 전진, 회전→전진 반복, 전후진 반복, 0/250/500/750/1000 입력 변화. 추가로 크루즈의 무거움/낮은 마찰, 무게중심 편차, 센서 지연 60ms 조건에서 전진·회전·아크를 검증했다.
- 크루즈 최대 입력 1000 지속 전진의 최대 기울기는 약 **4.30도**, 기울기 정지 없음. 이전 998 입력에서 약 5.24초 후 정지하던 단순 재현 및 원본 앱 조작 순서 재현 모두 수정 후 안전 정지 없이 통과했다. 재현의 센서 난수/전송 타이밍은 실제 사건과 완전히 같지는 않다.
- 처음 29조건에서 트롯 후진(약 9초)과 하이 스텝 후진(약 50초)이 실패했다. 두 조건의 후진 제한 수정 후 각각 60초를 다시 검증하여 약 5.68/5.78도 이내, 발 이외 접촉 없이 정상 정지했다. 다른 27조건은 이 변경에서 사용하지 않는 후진 제한 분기이므로 결과를 유지했다.

최종 결과는 `simulation/mujoco/high_speed_balance_validation.json`, 수정 전 실패 결과는 `simulation/mujoco/diagnostics/high_speed_balance_before_reverse_limits.json`, 사건 재현 비교는 `simulation/mujoco/diagnostics/balance_v3_incident_replay.json`이다. 전체를 재실행하려면 `validate_high_speed_balance.py`를 사용한다.

## 적용

MuJoCo를 재시작한 뒤 TCP에서 `rev=balance-v3-sim safety=ok balance=active profile=cruise reverse_limit=1000`을 확인했다. iPhone에 V0.3.3 (9) Debug를 설치했다. 실물 로봇 펌웨어는 변경/업로드하지 않았다.

기울기 감지 임계값 12도와 안전 정지는 완화하지 않았다. 추정 물성/센서 모델에서 위 조건을 검증한 결과이며, 모든 지형·장시간 운용 또는 실물 무전도를 보장하는 것은 아니다.

후속 크루즈 속도/매끄러움 개선은 [SMOOTH-CRUISE-2026-09-09.md](SMOOTH-CRUISE-2026-09-09.md) 참조. 앱의 안전 정지 수정은 유지한다.
