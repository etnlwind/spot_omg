# 80mm 동역학 지지력 예측 제어 — 2026-09-11

## 상태

`cushion_dynamics_wbc80` / **80mm · 동역학 지지력 예측 · 실험**.
구현과 물리 합격은 구분한다. 현재는 **검증실패**이며 기존 기본 정책을 대체하지 않는다.
실물 펌웨어·서보 보정값·iPhone 설치본은 변경하지 않았다.

## 구현한 계산

1. **센서 기반 상태 추정**: 40ms 지연·양자화된 관절 위치, 전달된 BNO055 자세와 각속도, CAD 기구학을 사용한다. 지지 다리의 속도로 몸체 속도를 추정한다. 수평 바닥과 예정된 접촉을 가정하므로 실제 접촉 센서/정밀 상태 추정기와 같지 않다.
2. **0.96초 지지력 예측**: 12구간 × 80ms의 선형화된 질량중심 MPC. 지지 다리 전환, 중력·관성, 단방향 접촉, 마찰 제약과 예측 좌우/높이 오차 ±10mm를 계산한다. 80mm 보폭과 1.44초 주기를 줄이지 않는다. 미래 관절 토크는 이 단순 모델에 포함되지 않으며 다음 단계에서 현재 시점의 토크를 제한한다.
3. **전신 역동역학 QP**: `M qdd + h = Sᵀ τ + Jᵀ f`를 사용해 관절/몸체 가속도와 지지력을 함께 구한다. 부유 몸체의 운동 방정식, 모터 토크·속도 한계, 관절 범위는 제약이다. 접촉 유지·몸체 자세·스윙 발 추종은 가중 작업이며 미달 오차를 기록한다.
4. **쿠션 지지력 분배**: 실제 쿠션 메시의 최저점에서 1mm 이내인 꼭짓점 중 앞뒤·좌우 극점을 선택한다. 그 영역 밖의 지지 모멘트를 임의로 만들어 주지 않는다. MPC는 발별 점 접촉 근사이고 전신 QP는 이 유한 영역을 사용하므로 두 모델의 차이도 남아 있다.
5. **위치 서보 변환**: 계산한 몸체 가속도로 발 위치를 보정하고 CAD IK로 J1/J2/J3를 계산한다. 하중 보상은 자세 보정과 분리해 스윙 때 이전 지지 토크가 남지 않도록 한다. 실제 서보 경로에는 기존 양자화·지연·가속도·토크 제한이 모두 남는다. 이 변환은 계산한 토크를 정확히 실행하지 못하며, 예상 토크 차이를 기록한다.

실행 중에는 평가용 실제 접촉력, 실제 몸체 위치/속도, 실제 모터 토크를 읽지 않는다. 평가기는 이를 별도로 사용한다. 제어기용 MuJoCo 데이터는 물리 실행 데이터와 분리되어 있다. 몸체를 고정하거나 실측 상태를 덮어써 성공시키지 않는다.

## 모터와 실패 처리

- J1/J3 STS3215, J2 STS3250의 기존 추정 스펙을 유지한다.
- 후보의 `rated_factor=3`은 제어 계산에서 정격을 넘는 순간 토크를 검토한다는 의미다. 실제 시뮬레이터의 stall/torque-speed/battery 제한을 높인 것이 아니다. 정격 초과율은 별도로 공개한다.
- QP가 실패하면 마지막 유한 목표를 유지하고 실패를 기록한다. MPC 실패 시에는 현재 시점 QP로 돌아가며, 이를 MPC 성공으로 세지 않는다. 기존 안전 정지 조건은 유지한다.
- 센서 누락/비활성화 때 자세·하중·예측 상태를 지운다. 기존 IMU 안전 처리와 Stop은 유지한다.
- 지지력 해가 있다는 것, 위치 서보에서 그 힘이 재현된다는 것, 실제 보행이 합격한다는 것은 서로 다른 검증이다.

## 초기 구현에서 발견해 수정한 사항

- 움직임 시작 때 실제 목표 진폭은 0인데 처음부터 접촉을 두 발로만 가정하면 하중이 갑자기 이동했다. 현재는 목표 발 높이와 전달된 관절 기구학을 이용해 짧은 접촉 전환을 허용한다. 보행 시계에 네 발 대기 시간을 추가하지 않는다.
- 지지 하중 보상을 자세 보정 필터에 합치면 4° 보상이 빠지는 데 약 0.32초가 걸렸다. 스윙 구간까지 하중 보상이 남아 발 들림을 방해하므로 분리했다.
- 모든 목표 각도에 1°/20ms 제한을 걸면 정상 스윙 궤적도 느려졌다. 후보는 하중/자세 보정의 변화율과 전체 명령 한계를 구분한다.
- 예측 QP의 m/rad/N 크기 차이는 변수·제약 정규화로 처리했다. 수렴 실패를 물리적 불가능과 동일시하지 않는다.

## 검증 범위

- 호스트 수치 검사: 중력 부호, 마찰, 토크 한계, 불가능한 운동의 거부, CAD 전체 운동 방정식 잔차, 시작 접촉, 센서 누락 초기화, 예측 접촉 일정 및 높이/좌우 제한.
- 물리 검증: 60초 직진(공통 초기화 5초 뒤), 20초 대각선 이륙/착지 측정, 정지 전환 및 조건 변화.
- 실제 설정 readback, 실제 위치 유지, 실제 로봇 전체 보행은 **미실시**.
- STS3250의 방향·누적 좌표 기준은 [실기 기준](STS3250-POSITION-CONTROL.md)을 유지한다.

Stop 후 정지와 자세 전환 완료는 확인했다. 다른 조건의 품질 합격을 의미하지 않는다. 40mm로 스윙 높이만 늘린 별도 후보는 4.32초에 기울기 안전 정지했으므로 채택하지 않았다.

- 60초 제어 프레임 3001개 중 전신 QP 실패 2개, MPC 미가용 20개. 미가용 시 현재 시점 QP로 돌아간 프레임도 실패로 센다.
- 위치 서보 변환 전후의 추정 토크 차이는 최대 20.46Nm였다. 실제 모터가 이 토크를 냈다는 뜻이 아니다. 실제 모터 한계에서 잘리는 큰 명령 오차가 남았다는 뜻이다.
- 실제 모터 정격 초과 비율 평균 29.2%, 토크 포화 비율 평균 6.0%.
- 병렬 물리 시험·영상 렌더링 중 측정한 계산 시간 중앙값 9.02ms, 95백분위 29.15ms. 20ms 초과 333프레임. 실제 시간 제어기로 배포 가능한 성능이라고 판정하지 않는다.
- 호스트 검사 33개 통과. 물리 품질 판정은 검증실패. 실제 TCP/Bluetooth/iPhone 설치 및 실물 시험은 이 변경에서 수행하지 않았다.

남은 핵심은 서보의 내부 목표 필터·명령 지연까지 포함한 위치 명령 최적화와 접촉/몸체 상태 추정이다. 예측 지지력을 위치 목표에 보상량으로 붙이는 근사만으로는 목표 수평/동기화를 달성하지 못했다.

## 재현

저장소 루트에서 기존 `spot_omg` 환경을 사용한다.

```sh
/opt/anaconda3/envs/spot_omg/bin/python -m pip install -r simulation/mujoco/requirements-wbc.txt
/opt/anaconda3/envs/spot_omg/bin/python -m pytest -q simulation/mujoco/test_dynamics_wbc.py simulation/mujoco/test_support_shift.py
/opt/anaconda3/envs/spot_omg/bin/python simulation/mujoco/validate_dynamics_wbc.py
/opt/anaconda3/envs/spot_omg/bin/python simulation/mujoco/validate_dynamics_wbc.py --conditions
```

별도 MuJoCo 창으로 실험 정책을 열 때(실물/기존 TCP 연결을 사용하지 않음):

```sh
/opt/anaconda3/envs/spot_omg/bin/mjpython simulation/mujoco/virtual_robot.py --viewer --no-ble --no-video --host 127.0.0.1 --port 8875 --experimental-profiles simulation/mujoco/upright_profiles.json --profile cushion_dynamics_wbc80 --foot-cushion simulation/mujoco/foot_cushion_10mm.json
```

## 참고와 구현 범위

- [Kim et al., 2019, Highly Dynamic Quadruped Locomotion via Whole-Body Impulse Control and Model Predictive Control](https://arxiv.org/abs/1909.06586): 질량중심 예측과 전신 운동 방정식을 분리하는 구조를 참고했다. 논문의 WBIC 전체나 실물 Mini Cheetah 성능을 재현했다고 주장하지 않는다.
- [MuJoCo Computation](https://mujoco.readthedocs.io/en/stable/computation/index.html): 질량 행렬·bias·Jacobian을 이용한 부유 몸체 역동역학.

현재 구현의 정확한 명칭은 **질량중심 MPC + 전신 역동역학 QP + 위치 서보용 근사 변환**이다.
