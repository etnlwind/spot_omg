# 보행 재개: 회수 궤적의 역행 제거와 남은 끌림

2026-09-16. 사용자의 Landing/J3 기구적 끝점 설명을 반영한 뒤 보행 작업으로
돌아왔다. 실기 구동·OTA는 수행하지 않았다. 마지막 실기 확인은 v75,
Landing·토크ON이며 현재 상태를 새로 조회한 것은 아니다.

## 이번에 확인한 문제

기존 **V6.2.7 후보 r2**의 J2/J3 추가 파형이 서로 다른 시점에 최대가 되면서,
회수 초반 발끝 목표가 앞으로 갔다가 다시 뒤로 약 **2.88mm** 이동했다.
정상 보행 회수의 약 **8.4~13.6%** 구간이며 네 발에서 공통으로 재현된다.
위상 정지 시간이 0이어도 이런 궤적 역행은 생긴다. 이 문제는 서보 가속도
가정이나 접지 동역학 없이 CAD 목표 계산만으로 확인된다.

등록된 V6.2.6의 전체 원인이나 실제 로봇 멈칫거림의 유일한 원인으로 확대하지
않는다. 이 역행은 오프라인 r2 후보에 더한 독립 관절 파형에서 확인한 것이다.

- [기하 분석 그림](../artifacts/s-native-v6-2-7/recovery-monotonic/geometry/recovery-geometry.png)
- [네 발 수치](../artifacts/s-native-v6-2-7/recovery-monotonic/geometry/summary.json)

## 후보 r3의 변경

`config/experiments/post_push_j2_j3_monotonic.json`으로 r2를 보존하고 분리했다.
기존 quintic X 궤적은 그대로 두고, 추가 J2/J3 파형으로 얻는 **높이 변화만**
대각선 쌍에 공유한 다음 J2/J3를 함께 역기구학으로 계산한다.

- 예정된 밀기 구간이 끝난 뒤 발 들기와 J3 접기를 시작한다.
- 회수 중 X 역행이나 별도 대기 구간을 넣지 않는다.
- 지지 끝점 +20/-125mm, 첫 FR/RL 내딛기, FR J1 두 배 진입, 이후 J1 유지,
  대각선 상대 X/Z 동기, 두 번의 STOP→S 배치를 유지한다.
- 정상 주기 J3 명령 범위는 CAD 좌표 약 **76.16~98.34°**, 목표 들기 최대는
  약 **14.55mm**다. 코드 Landing 목표 130°를 추가 접힘 목표로 사용하지 않는다.
- 이는 기구적 끝점의 네 축별 정밀 측정이 아니다. 시뮬레이터의 기존 J3 한계
  150°도 이번 설명으로 검증된 수치가 아니며, 이번 후보는 그 끝점을 사용하지 않는다.

CAD에서는 J3를 증가시키면 J2축→J3축→쿠션 중심으로 측정한 기하학적 각도가
작아진다. 이 기하 각도는 서보 원시값, 코드 관절각, 사진의 투영각과 구분한다.
이전 RR 실기 응답 시험은 반대로 원시값을 증가시켜 코드 J3를 감소시켰으므로,
그 기록으로 접힘 성능이나 가속도 제한을 입증하지 않는다.
[실기 기록의 정정](SERVO-ACCELERATION-VALIDATION-2026-09-16.md).

## 검증 결과와 한계

회귀 **4개 통과**: 두 후보의 출발/대각선/지지/정지 규칙, 실험 종료 시 기존
메서드·프로필 복구, 기존 r2 역행 재현 및 r3 역행 제거를 검사했다.
기하 검사에서 0.01mm보다 큰 역방향 증분의 누적은 **2.88→0mm**였다.

기본 추정 물리, 11.1V 개방 전압 설정, 2초 대기→30초 전진→4초 정지:

| 항목 | 기존 r2 | 후보 r3 |
|---|---:|---:|
| 보행/STOP 보호 중단 | 없음 | 없음 |
| 정상 보행 위상 정지 누적 | 0s | 0s |
| 보행 최대 절대 roll/pitch | 3.93° | 4.94° |
| 정상 보행 roll RMS | 1.33° | 1.40° |
| 정지 후 실제 관절 최대 S 오차 | 0.99° | 0.99° |
| FL 접촉 끌림 누적 | 2.46s | 2.44s |
| FR 접촉 끌림 누적 | 2.70s | 2.06s |
| RL 접촉 끌림 누적 | 2.74s | 2.42s |
| RR 접촉 끌림 누적 | 2.22s | 2.52s |

끌림은 예정 회수 중 하중>1N, 실제 접촉 재료점의 전진 미끄럼>20mm/s,
몸체 기준 발 전진>20mm/s가 함께 발생한 20ms 표본으로 집계한다.
발별 시간이므로 합계를 전체 영상 시간과 혼동하지 않는다. **RR은 증가했고,
몸체 흔들림도 개선되지 않았다. 궤적 결함은 수정했지만 보행 품질 합격은 아니다.**

추가 비교에서 높이 4mm 증가는 8초 최대 기울기 7.74°, 위상 정지0.12s로
악화됐다. 파형 최대 시점을 함께 22%로 늦춘 r3b는 30초 보행/정지는 끝났지만
최대 기울기6.64°, roll RMS2.12°로 악화되어 선택하지 않았다. 실험 설정과
실패 수치를 보존했다. 높이/접힘을 무조건 늘리는 해법으로 채택하지 않는다.

별도 8조건 검사: 0.3/0.8/1.5/4초 조기 STOP, 개방 전압10.5/12.6V,
추정 서보 가속도 환산0.5배/2배에서 모두 보호 중단 없이 S로 돌아왔다.
가속도 환산 변화는 **불확실성 검사**이며 설정 레지스터/실기 제한을 바꾸거나
실측값으로 채택하지 않는다. 두 배 조건의 정지 최대 기울기는8.13°였다.
이 결과도 실기 안정성이나 실제 가속도 검증을 대신하지 않는다.

## 영상과 남은 끌림 위치

[4방향 영상](../artifacts/s-native-v6-2-7/recovery-monotonic/video/capture/four-views.mp4):
**2초 대기 + 8초 보행 + 4초 정지**, 25fps/350프레임/14초.
앞·뒤·위·옆은 같은 상태를 렌더링한다. 질량·쿠션·위상·기울기·접촉 하중·높이,
J1/J2/J3 목표/실제값·전압·추종 상태를 포함한다.

영상의 J3 FOLD/OPEN은 최종 IK **명령의 증가/감소**로 표시한다. 이전처럼
추가 파형의 정점을 최종 관절의 펴기 시작이라고 표시하지 않는다.
실제 동작은 바로 아래 실제 관절값과 접촉 하중/높이로 따로 읽는다.

영상 시간 기준 주요 잔여 구간(보행은2초에 시작):

- RR 2.90~3.02초, 5.82~5.90초, 7.18~7.26초.
- RL 3.58~3.68초, 3.70~3.78초, 5.12~5.26초.

이는0.08초 이상 지속된 구간이며 앞발의 짧은 접촉도 남는다.
[전체 이벤트](../artifacts/s-native-v6-2-7/recovery-monotonic/video/drag-analysis/events.json).
영상과 접촉 분석 재생의 관절 오차는0°였다. 정지명령10초, S 복귀12.60초,
최종 목표 오차0°, 실제 최대0.99°다.

## 다음 작업

현재 앱/시뮬레이터 등록 기본 모델은 V6.2.6, 실기 펌웨어는 v75다. r3는
오프라인 비교 후보로 보존하며 새 기본 모델이나 실기 펌웨어로 승격하지 않았다.

남은 핵심은 실제 회수 전진과 접촉 해제의 동기다. 특히 RR/RL의 회수 중반
접촉을 목표 파형, 시뮬레이터 내부 참조, 실제 관절/하중으로 나눠 확인한다.
실기 시험을 재개할 때는 접힘 방향과 가동 여유부터 확인하고, Landing 도달 후
토크 해제/설치 절차를 지킨다. 기존 가속도 응답 자료를 접힘 실측으로 재사용하지 않는다.

재현 도구: `audit_recovery_geometry.py`, `compare_recovery_clearance.py`,
`validate_recovery_candidate.py`, `capture_s_native_balance.py`, `locate_recovery_drag.py`.
앞의 둘과 마지막 둘은 `simulation/mujoco/scripts/analysis/`, 검증 도구는
`simulation/mujoco/scripts/validation/`에 있다. 결과는 모두
`artifacts/s-native-v6-2-7/recovery-monotonic/`에 저장했다.
