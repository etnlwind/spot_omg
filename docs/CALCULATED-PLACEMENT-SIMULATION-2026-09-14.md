# 정적·가속도 반영 착지점의 실제 MuJoCo 비교

정적 계산값과 가속도 반영 계산값을 각각 적용하고 실제 물리 상태를 30초씩 녹화했다. **두 변경안 모두 기울기 안전 정지로 실패했다.** 착지점의 기하학적 도달 가능성과 힘 평형 계산이 보행 중 궤적 추종·지지력 생성을 보장하지 않는다는 결과다. 실물 펌웨어와 앱에 승격할 최종 보행값은 확보하지 못했다.

## 동일 시험 조건

- 총질량 **2.754kg**은 배터리 포함 실측값이다. 질량분포·관성·모터 모델·쿠션 물성은 추정값을 포함한다.
- 쿠션 형상 유지: 높이 27mm, 바닥 최대 지름 37.3mm. 3S 11.1V 명목 전원, J2 STS3250 4개, J1/J3 STS3215 8개.
- 주기 1.35초, duty 0.52, 명목 발 궤적 X 이동폭 96mm, 들림 32mm, 시작 램프 1초. 계산에 맞추려고 주기나 보폭을 줄이지 않았다.
- 세 경우 모두 기존 heading/balance 보정은 OFF. 가속도 반영안은 별도의 착지점·자세 모멘트 계산을 사용한다.
- 이번 기준선은 명시적 Cartesian 96mm 궤적이다. 과거 CAD 각도로 생성했던 원본과 비트 단위로 동일하지 않으며, 3.2초 주기의 FF 후보와도 다른 시험이다.
- 물리 timestep 0.5ms, 상태 기록 50Hz, 녹화 25FPS. 중력, 충돌, 마찰, 서보 속도·토크 제한을 유지했다.
- 10초 정지 후 20초 전진을 요청한다. 안전 정지가 발생하면 전진 명령을 다시 보내지 않고, 기존 Stop 처리와 이후 물리 움직임을 30초까지 기록한다.

## 적용한 목표값

### 1. 정적 계산 적용

[단순 계산 보고서](SIMPLIFIED-DIAGONAL-SUPPORT-2026-09-14.md)의 **각 발 X −46.54275mm**를 적용했다. 대각선 두 발이 스윙하는 동안 이전 오프셋에서 새 오프셋으로 quintic 보간하고, 이후 지지 구간에는 그 몸체 좌표 오프셋을 유지한다. 지지 중 몸체 좌표 오프셋 유지가 세계 좌표에서 발의 완전한 고정을 뜻하지는 않는다.

이 값은 원본 10.80초의 FR/RL 두 점 지지를 정적으로 평형에 맞춘 값이다. 한 시점의 정적 해를 모든 주기에 공통 적용했을 때도 안정한지를 확인한 실험이며, 처음부터 최적 보행으로 검증된 값은 아니다.

### 2. 가속도·자세 모멘트·공통 착지면 반영

몸체 목표 속도는 명목 `96mm / (1.35s × 0.52) = 0.136752m/s`이며 시작 램프를 적용한다. 각 스윙 시작에 다음 착지 시점의 속도와 가속도 참조를 평가한다. 이는 목표 몸체 속도이며 실제 측정 속도나 시작 구간의 모든 발 궤적 미분값과 동일하다는 뜻은 아니다.

```
a_req = a_reference + (v_reference − v_estimate) / (T × duty)
Fz = m(g + az)
Px = Cx − h ax/(g + az) − τy/Fz
Py = Cy − h ay/(g + az) + τx/Fz
```

`P`는 요구 힘·모멘트에 해당하는 지지 압력 중심이다. 두 발의 공통 세계 X 위치를 이동시켜 지지선이 이 점을 지나도록 계산한다. 식은 [MIT Underactuated Robotics의 CoP·모멘트 관계](https://underactuated.csail.mit.edu/humanoids.html)를 따른다. 수평면의 점 접촉, 지정한 수평 각운동량 변화율, 수직 각운동량 변화율 0이라는 가정이 있다.

- 지연된 IMU와 40ms 지연·4096단계 양자화 관절 피드백으로 기구학적 속도와 지면을 추정한다. MuJoCo 정답 접촉력·COM 가속도는 제어 입력으로 사용하지 않는다.
- 예정 지지발의 미끄러짐 없는 접촉을 가정한 속도 추정이다. 접촉 상태가 계획과 달라지면 이 가정도 깨질 수 있다. 관측 누락·오래된 표본은 별도 검사한다.
- 현재 전달된 기울기와 추정 지면을 다음 착지까지 고정해 예측한다. CAD 복합 관성과 목표 각가속도로 자세 모멘트를 근사하며 스윙 다리의 각운동량을 별도로 예측하지 않는다.
- 가속도 요청은 축별 ±1m/s² 상한을 두고 원래 요청값과 제한 여부를 기록한다.
- 두 발의 최종 세계 Z를 같은 추정 지면으로 맞추고 쿠션의 회전된 최저점으로 IK를 다시 계산한다. 몸체가 기울어져 있으면 두 발의 몸체 좌표 Z와 J2/J3 각도는 달라질 수 있다.
- 최종점의 관절 제한·IK 잔여·양의 수직 반력·접촉별 요구 마찰을 검사한다. 이 계산된 힘을 위치 서보에 직접 명령하는 구조는 아니다. 토크 MPC/WBIC를 구현한 것이 아니다.

| 착지 계획 순서 | 대각선 쌍 | 계획 ax / ay (m/s²) | 각 발의 X 보정 (mm) | 각 발의 몸체 Z 보정 (mm) |
|---|---|---|---|---|
| 1 | FR/RL | +0.346 / 0.000 | −57.84 / −57.84 | +1.83 / +1.83 |
| 2 | FL/RR | +0.035 / −0.014 | −71.05 / −71.05 | +8.72 / +8.82 |
| 3 | FR/RL | +0.008 / −0.124 | +38.85 / +38.64 | +11.13 / +13.61 |
| 4 | FL/RR | +0.018 / −0.003 | −2.29 / −2.33 | +17.16 / +17.63 |
| 5 | FR/RL | −0.158 / −0.050 | −62.43 / −54.04 | +27.67 / +92.54 |

이는 각각의 스윙 종료 목표이며 스윙 시작에 즉시 이 위치로 점프시키지 않는다. X는 기본 궤적에 대한 보정량이므로 어깨 기준 최종 절대 착지 X나 전체 보폭과 혼동하면 안 된다. 가속도 반영 목표는 한 개의 고정 상수가 아니다. 위 5번째 계획처럼 기울어진 상태에서 다음 목표가 크게 달라졌으며 이 실험에서는 실제 추종에 실패했다.

## 실제 물리 결과

아래 통계 구간은 전진 시작 10초부터 각 안전 정지 시점까지다. 기준선은 30초까지다. **구간 길이가 달라 RMS 숫자를 그대로 개선율로 비교하지 않는다.**

| 항목 | 기준선 | 정적 −46.54mm | 가속도 반영 |
|---|---:|---:|---:|
| 안전 정지 시각, 영상 기준 | 없음 | 11.84s | 13.14s |
| 정지 전 전진 요청 지속 시간 | 20.00s | 1.84s | 3.14s |
| 최대 roll | 10.83° | 14.44° | 21.61° |
| 최대 pitch | 5.21° | 6.73° | 12.62° |
| roll RMS | 7.38° | 4.41° | 6.05° |
| pitch RMS | 3.07° | 2.10° | 4.32° |
| COM 높이 최대−최소 | 23.87mm | 9.29mm | 55.23mm |
| 최대 관절 목표−실제 차이 | 18.75° | 16.67° | 51.34° |
| 명령 각도 차분의 최대 속도 | 3.00rad/s | 2.94rad/s | 3.78rad/s |
| 전진 변위 | 2.297m | 0.208m | 0.401m |

중간 스윙 구간에서 실제 발 하중이 1N을 넘은 표본 비율(FL/FR/RL/RR):

- 기준선: 0.0 / 4.0 / 59.8 / 59.6%.
- 정적 보정: 13.6 / 55.0 / 25.0 / 4.5%.
- 가속도 반영: 29.5 / 59.3 / 25.4 / 34.1%.

기준선도 수평 기준을 통과하지 않는다. 새 보정안은 모두 `tilt` 안전 정지다. 가속도 반영안의 높이 변동 55.23mm와 관절 추종 오차 51.34°는 분명한 실패다. 정적 보정보다 늦게 정지했다는 이유로 개선 완료라고 판정하지 않는다.

지금 확인한 한계는 **착지 끝점의 평형 계산만으로 전체 스윙·지지 전환의 물리적 추종을 확보하지 못했다는 것**이다. 느린 모터 하나의 탓으로 결론 내릴 근거는 없다. 다음 구현에서는 예정 착지점뿐 아니라 전체 구간의 관절 속도·가속도·토크와 접촉 전환을 함께 제한하고, 실제 지지 상태와 추정의 불일치를 진단해야 한다.

## 검증 범위와 재현

- 수학 검사 12개 + 착지 어댑터 검사 14개 통과. 독립 리뷰로 기울어진 CAD의 공통 지면, 모멘트, 센서 지연·누락, 시작 이력, 경계 연속성을 확인했다.
- 기존 preview 상태 회귀 검사 3개 추가 통과. 총 29개.
- 물리 시뮬레이션과 동영상 상태 기록은 위와 같이 실패를 확인했다.
- 실기 설정 readback, 실물 위치 유지 시험, 실물 전체 동작 시험은 수행하지 않았다. 이번 변경은 시뮬레이션 실험 도구이며 실물·앱 정책으로 적용하지 않았다.
