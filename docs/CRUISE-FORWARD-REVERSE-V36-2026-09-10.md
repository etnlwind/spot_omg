# V36 크루즈 전진을 후진 설정에 맞춤

사용자 요청: `크루즈 · 넓은 보폭`은 후진이 잘 되므로 전진에도 같은 보행 설정을 사용한다.

## 변경

공유 manifest의 cruise.params를 기존 turn_reverse_params와 동일하게 변경했다. 후진/회전 설정과 J2 스포츠의 V35 보정은 유지한다. 전진 명령 부호를 뒤집은 것이 아니라, 전진 방향을 유지하면서 보폭·들림·타이밍을 맞춘 것이다.

| 항목 | 기존 전진 | 변경 전진 / 기존 후진 |
|---|---:|---:|
| 기준 주기 |0.8초|1.05초|
| 지지 비율 |64%|60%|
| 보폭 매개변수 |65mm|80mm|
| 발 들림 매개변수 |7mm|12mm|

입력에 따른 공통 주기/진폭 조절은 기존대로 적용된다. 좌표 x 오프셋=-35mm와 down=201.75mm는 유지한다. 실물의 실제 이동 속도나 발 높이가 매개변수와 동일하다는 뜻은 아니다.

## 검증

- 공유 C 전진/후진의 발 높이 일치와 기준 위치 주위의 앞뒤 궤적 대칭 회귀 추가.
- 공유 커널 및 펌웨어 호스트 테스트43개 통과.
- 기존 검증 스크립트의 전진 매개변수 하드코딩을 제거하여 현재 배포 manifest와 공유 C drive를 직접 검증한다.
- 전진/후진/회전/전환 및 무게·마찰·무게중심·센서 지연 조건17개 통과. 명령 구간은 각60초이며 최대순간기울기6.56°, 중단/비발 접촉 없음.
- 모든 앱 정책의60초 전진 속도를 다시 측정했다. 새 크루즈 속도는 추정 물리에서0.157175m/s이며 앱 소스의 속도 표기를0.157m/s로 재생성했다. 실제 폰에 앱 V0.5.0 (34) 설치를 완료했다.
