# J2 스포츠 모드와 전체 정책 속도 표시 — 2026-09-10

## 정책

기존 jointfast를 유지하고 **J2 협응 · 스포츠** (`jointsport`)를 추가했다. 최대 전진 보폭 105mm, 주기 1.5초, 지지 비율 0.59, 명령 발높이 15mm. jointfast의 보폭 85mm/지지 비율 0.64에서 조정해 스윙 시간을 0.54→0.615초로 늘렸다. J2/J3의 기존 속도 선행 계수 40/10ms 상당은 유지했다.

저속 전진·제자리 회전·후진은 이전 joint 파라미터를 사용한다. 전진 입력 0–50%에서 스포츠 파라미터로 부드럽게 보간한다. 모터 한계·중력·마찰·질량은 수정하지 않았다. 키 G로 선택할 수 있다.

## 배포 제어 경로의 60초 최대 전진 (nominal, seed55)

| 항목 | jointfast | jointsport |
|---|---:|---:|
| 전진 방향 속도 (m/s) | 0.107 | 0.145 |
| 기울기 RMS (°) | 0.672 | 0.867 |
| 최대 축 기울기 (°) | 1.940 | 3.133 |
| 수직 흔들림 표준편차 (mm) | 1.848 | 2.255 |
| 수직 가속도 RMS (m/s²) | 0.796 | 1.104 |
| 절댓값 기계출력 평균 (W) | 2.615 | 3.595 |
| 앞왼 주기 최고 발높이 중앙값 (mm) | 14.36 | 9.77 |
| 앞오른 주기 최고 발높이 중앙값 (mm) | 12.48 | 12.03 |
| 뒤왼 주기 최고 발높이 중앙값 (mm) | 8.43 | 11.64 |
| 뒤오른 주기 최고 발높이 중앙값 (mm) | 6.79 | 13.39 |

기존 빠른 모드보다 약 36% 빨라졌다. 기본 모델 3개 seed 모두 약 0.145m/s, 기울기 RMS 0.828–0.867°. 중간 스윙에서 지면 여유 1mm 미만 비율은 약 43→28%로 줄었다. RMS 기울기·각속도·모터 부하는 늘었다. 최고 발높이와 모든 스윙 시점에서 충분히 지면을 피한다는 것은 다르다.

전진 7개(기존 jointfast 기준 포함), 좌우 제자리/전진회전/회전→전진/후진회전 8개, 정지·재출발 반복 2개 모두 넘어짐 없이 통과했다. 회전 조건 최대 기울기는 약 5.77°로 전진보다 크다. 무게중심 이동 조건에서는 RMS 약 1.26° 및 한 앞발 들림 약 3mm가 남는다. 실물 성능과 열적 연속운전을 보장하지 않는다. 실물 펌웨어 업로드/작동은 하지 않았다.

짧은 주기·높은 자세 후보는 흔들림 또는 발 끌림이 커져 채택하지 않았다. 임시 후보 커널의 장시간 결과와 실제 배포 경로 결과는 시작 구간 파라미터 보간이 달라 다를 수 있다. 위 표 및 앱 속도에는 최종 배포 경로 결과를 사용했다.

## 모든 앱 정책의 속도

`benchmark_profile_speeds.py`로 전체 12개 정책을 동일한 추정 물리 모델, seed55, 최대 전진 60초에서 측정했다. 5–62초의 변위를 처음 전진 방향에 투영하여 평균 속도를 계산한다. 60초를 마치고 정지했으며 안전 오류·비발 접촉이 없는 경우에만 숫자를 게시한다. 이 기준은 속도 측정 성공 기준이며 모든 정책이 같은 수평 유지/발높이 기준을 충족한다는 의미는 아니다.

`config/locomotion_speed_benchmarks.json` → `tools/generate_gait_speed_labels.py` → 앱 프로필 표시를 생성한다. 프로필 manifest 해시와 전체 정책 목록 일치를 검사한다. 모든 정책 선택 항목과 선택된 이름에 `(0.145m/s)`처럼 소수점 3자리로 표시한다. 실패 또는 잘못된 속도는 사용자가 요청한 정확한 문구 **(검증실패)**로 표시한다. 이번 전체 속도 측정에서는 12개가 모두 통과했다.

| 정책 | 앱 표시 속도 |
|---|---:|
| legacy | 0.055m/s |
| crawl | 0.027m/s |
| cruise | 0.212m/s |
| trot | 0.198m/s |
| highstep | 0.082m/s |
| lift | 0.082m/s |
| imu | 0.077m/s |
| level | 0.092m/s |
| level15 | 0.076m/s |
| joint | 0.086m/s |
| jointfast | 0.107m/s |
| jointsport | 0.145m/s |

앱에 표시하는 값은 시뮬레이션 기준 참고 속도다. 실제 로봇 속도나 실시간 현재 속도가 아니다. 화면에도 이 기준을 안내한다.
