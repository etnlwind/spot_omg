# V6.2.1: 교차 감속과 이동 중 무릎 회수 개선

사용자 요청 순서대로 교차할 때 멈칫하는 현상을 먼저 수정·검증하고,
그 상태를 보존한 뒤 R3(J3) 회수 궤적을 조정했다. 이후 사용자 지정 이름인
`s_native_v6_2_1`로 분리했다. V6.2/V6.1을 보존했다. 후속 실기 이식과
설치 상태는 [V6.2.1 실기 펌웨어 v63](S-NATIVE-V621-FIRMWARE.md)에 기록한다.

## 적용한 동작

- 뒤쪽 추가 이동량을 S 뒤쪽에만 몰아서 적용하던 함수를 전체 왕복 구간에
  분산했다. 최대 전진 시 앞 +20mm, 뒤 −125mm와 주기 2초는 유지한다.
  대각선 상대 X/Z·타이밍을 공유하며 중간 정지나 위상 대기를 추가하지 않는다.
- 기존 V6.2의 교차 속도는 75.0mm/s로 최고 460.8mm/s의 16.3%였다.
  V6.2.1은 교차 222.7mm/s, 최고 350.7mm/s로 교차 감속을 줄였다.
  수치는 몸체에 대한 명목 발 궤적이며 로봇 몸체의 전진 속도가 아니다.
- 회수 높이의 최대값은 12mm로 유지하면서 높이 곡선의 지수를 0.5→0.25로
  바꿨다. 이동 중 무릎을 더 오래 접고, 전진 이동과 동시에 다시 펴서 착지한다.
  목표점에 도착한 뒤 별도로 펴거나, 먼저 들어 올린 다음 이동하는 분리 동작은 없다.
  J2/J3를 함께 IK로 풀어 지정된 발끝 X/Z 경로를 따른다.
- 기존 코드에서도 J3는 고정각이 아니었다. 이번 변경은 회수 후반의 굽힘과
  지면 여유를 늘린 것이다. J3 서보 굽힘각은 접을 때 증가하며, 링크 사이 안쪽
  각도는 감소한다. 방향/영점 변환은 변경하지 않았다.
- 두 걸음 Stop은 V6.2.1에서 1.6초(각 0.8초)로 조정했다. 1.2초를 유지한
  초기 후보는 출발 1.2초 뒤 정지 시험에서 기울기 보호가 발생했다.
  이 시간 변경은 정지 명령 이후에만 적용되며 보행 교차 대기가 아니다.
- Windows/iOS 목록 맨 위에 V6.2.1을 추가했다. 명시적 capability를 광고하는
  시뮬레이터와 실기 v63에서 기본 선택한다. 기존 실기 펌웨어는 지원되는 V6.1을 유지한다.

## 검증 결과와 남은 문제

추정 물성, 기존 서보 속도·추종 모델, 쿠션 충돌과 기울기/센서 보호를 유지했다.
전진 47.3%/100%, 시작 0.3초/1.2초 후 정지, 후진 60%, 좌우 회전,
전진+회전의 8조건 모두 보호 중단 없이 S 복귀했다. 실제 관절의 최종 S 오차는
최대 약 0.991°이며 관측된 로봇 내부 충돌 프레임은 0이다.

최대 전진 8초에서 X 이동 1.112m, 방향 변화 −1.451°, 보행 최대 기울기 5.451°,
정지 최대 기울기 5.012°였다. 출발 1.2초 후 정지 조건은 최대 8.448°였다.

**발 끌림 제거는 아직 완료되지 않았다.** 영상 4–10초의 회수 진행률 20–90%를
50Hz로 검사한 420개 발 표본 중 쿠션 접촉 하중이 0.5N을 넘은 표본이
V6.2의 117개에서 V6.2.1의 57개로 줄었다. 하지만 최저 실제 쿠션 간격은
−1.176mm로 접촉이 남았다. 이는 발별 표본 수이며 독립된 걸음 57회라는 뜻이 아니다.
명목 궤적이 공중을 지나거나 J3가 접힌다는 사실만으로 실제 무접촉을 선언하면 안 된다.

단순히 발 높이를 18–24mm로 늘리거나 주기를 짧게 하는 후보들은 기울기 보호가
발생했다. 지지 변위 제한 확대와 단순 자세 피드백 후보도 채택하지 않았다.
최종 적용본은 최대 높이·지지 변위 제한을 유지하며 검증된 곡선 변경만 포함한다.
정상 Stop의 명령/실제 접지 동기 한계도 이전 버전에서 이어진다.

호스트/시뮬레이터 시험과 Windows 빌드를 수행했다. iOS는 소스 반영만 했으며
Xcode 빌드·기기 설치는 미실시다. 후속 실기 설치/readback은 위 v63 문서를 참고한다.
실제 로봇의 위치 유지·전체 동작 시험은 별도 검증이 필요하다.

## 재현과 보존

```powershell
python -X utf8 simulation/mujoco/scripts/validation/validate_s_native_v62.py --profile s_native_v6_2_1 --output artifacts/s-native-v6-2-1/recheck
python -X utf8 -m pytest simulation/mujoco/tests/test_s_native_v621.py apps/windows/tests/test_protocol.py -q
```

- `artifacts/s-native-v6-2-1/validation/`: 최종 형상과 물리 시험.
- `artifacts/s-native-v6-2-1/recovery-comparison.json`: 교차 속도·J3·실제 접촉 비교.
- `artifacts/s-native-v6-2-1/video/four-views.mp4`: 2초 정지 + 8초 보행 + 4초 Stop/유지.
  앞·뒤·위·옆 동시 화면, 하중·발 높이·위상·기울기·J3·S 오차를 포함한다.
- `artifacts/s-native-v6-2-1/preservation.json`: V6.2 원본과 프로필 동일,
  전진·후진·회전의 604개 목표 자세 비교에서 최대 차이 0°.
- `artifacts/s-native-v6-2/recovery-fix/timing-fixed-s_native_gait.py`와
  `timing-final/`: R3 변경 전 교차 감속만 수정한 보존본과 8조건 검증.
- 초기 후보들은 이름 지정 전 `artifacts/s-native-v6-2/recovery-fix/`에,
  이후 후보들은 `artifacts/s-native-v6-2-1/`에 기록했다. 실패 후보를 배포하지 않는다.
