# IMU 보행 정책 — 2026-09-10

> 아래는 최초 v17 정책 기록이다. 최대 직진 흔들림을 재현하여 v18에서 수정했다. 현재 구현 및 검증은 [IMU 고속 안정화](IMU-FULL-SPEED-FIX-2026-09-10.md)를 참조한다.

기존 cruise/lift/highstep 및 기본 모드를 보존하고 독립 `imu` 모드를 추가했다. 발 궤적은 lift와 동일하다(최대 명령 발 높이 20mm, 보폭 파라미터 45mm, 기본 주기 1.05초). 아래 비교는 궤적을 바꾸지 않고 피드백만 바꾼 A/B 검증이다.

## 제어

- 기존 직진 heading hold 유지.
- 50Hz 제어에서 지연된 BNO055 자세 및 정수 필터의 각속도 추정치를 사용한다. 각속도는 별도 자이로 레지스터를 추가로 읽은 값이 아니라 Euler 변화율이다.
- 25ms 선행 예측의 추가 각도는 ±0.02rad로 제한한다. 센서 모델은 기본 20ms fusion delay, 100Hz 샘플링, 50Hz 폴링, 잡음/양자화를 유지했다.
- 보행 위상에서 예상 지지 비중을 계산한다. 이륙 전후와 착지 전후에 부드럽게 전환한다. 실제 발 접촉을 측정한 것으로 간주하지 않는다.
- J2/J3 길이 보정은 지지 비중 100%, 스윙 비중 65%로 배분한다.
- J1은 roll 방향과 좌/우 다리, 예상 지지 비중에 따라 보정하며 최대 ±1.5도다. 지지 다리와 스윙 다리의 부호가 다르다.
- pitch 기반 앞뒤 착지 위치 보정은 ±3mm로 제한한다. 스윙 중 늘어나 착지까지 유지한 뒤 초기 지지 구간에 해제한다.
- 기존 PI anti-windup, 관절당 0.3도/20ms 변화 제한과 최대 6도 보정 제한을 유지한다. 보정 IK가 불가능하면 추가 발 위치 보정을 단계적으로 축소한다.
- 정지/자세 전환에서는 기존 PI 경로로 돌아간다. IMU 불가 또는 balance OFF이면 적분을 지우고 기존 보정을 제한 속도로 해제한다. 센서 연속 실패·기울기·통신 watchdog 정지는 그대로 유지한다.

핵심은 `firmware/stm32-learning/Inc/balance_control.h`의 공통 C 구현이다. STM32 drive와 MuJoCo가 같은 함수에 위상과 IMU를 전달한다. MuJoCo의 실제 자세/접촉/외력은 센서 생성과 평가에만 사용하고 제어기에 직접 전달하지 않는다. 지지 다각형 기반 무게중심 이동, 접촉 센서, 토크 기반 전신 제어 또는 학습 정책을 구현한 것은 아니다.

## 사용

```bash
cd /Users/etnlwind/project/spot_omg
PYTHONPATH=tools/servo_tool:simulation/mujoco /opt/anaconda3/envs/spot_omg/bin/mjpython simulation/mujoco/virtual_robot.py --viewer --profile imu
```

정지 중 MuJoCo 키 `7`=IMU, `6`=lift, `3`=cruise. 원격 소유자가 없을 때 `W`=8초 보행, `Space`=정지. 콘솔에서는 `gaitprofile imu`. 수평 보정 OFF 시 이 모드의 새 자세 피드백도 꺼지며, heading ON/OFF는 기존처럼 독립 설정이다.

앱 소스의 정책 선택 목록에 `IMU 적응 · 지지 다리 보정`을 추가했다. 이번 작업에서 실행 중인 Mac/iPhone 앱 교체 설치와 실물 로봇 펌웨어 설치는 하지 않았다.

## 검증 결과

`simulation/mujoco/validate_imu_policy.py`로 10개 조건 × lift/imu = 20개 실행. 각 실행은 24초, 구동 요청은 20초이며 시작/종료 전환을 포함한다. 전부 safety=ok, 비발 접촉 없음, 정지 완료. 결과는 `simulation/mujoco/imu_policy_validation.json`.

| 조건 | lift 자세 RMS(도) | imu 자세 RMS(도) | 변화 |
|---|---:|---:|---:|
| 직진 | 1.430 | 1.336 | -6.6% |
| 제자리 회전 | 1.932 | 1.708 | -11.6% |
| 전진 회전 | 3.674 | 4.004 | +9.0% |
| 후진 회전 | 1.493 | 1.515 | +1.5% |
| 회전→직진 | 1.736 | 1.534 | -11.6% |
| roll 외란 | 1.409 | 1.344 | -4.6% |
| pitch 외란 | 1.417 | 1.365 | -3.7% |
| 센서 지연 60ms | 1.573 | 1.576 | +0.2% |
| 무게/마찰 변경 | 1.269 | 1.145 | -9.7% |

외란은 0.25Nm 토크를 각 1초씩 두 번 가했다. RMS는 roll²+pitch² 합의 평균 제곱근이며 초기 준비/최종 정지 구간은 제외한다. 결과는 단일 센서 난수 seed 및 추정 물성에 한정되므로 실물 성능 보장이나 통계적 우월성 주장이 아니다. 특히 전진 회전에서는 흔들림이 증가하여 기본 모드로 승격하지 않았다.
