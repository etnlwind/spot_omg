# Stand 45°보다 다리를 더 펴면 보행에 유리한가?

## 결론과 정책 제안

현재 코드의 Stand는 **J2=45°, J3=90°**이다. J2와 J3가 모두 0°일 때 두 링크가 펴지는 canonical 좌표다. 따라서 더 펴는 비교는 J2/J3를 함께 **40°/80°**, **35°/70°**로 줄인다. J2만 바꾸면 발의 앞뒤 위치도 바뀌어 동일한 비교가 아니다.

이번 추정 물리 모델에서는 조금 더 편 자세가 전진 효율에 유리했지만, 몸체 흔들림과 방향 편차의 절충이 있었다. 제안하는 정책은 다음과 같다.

- **현재 설치된 V15/정지·준비 기준:** 45°/90° 유지.
- **다음 평지 보행 실험 후보:** 40°/80°. 기존 Stand에서 부드럽게 준비 자세로 옮긴 뒤, V15의 보폭·발 높이·주기로 걷는 방식. 발 궤적의 명목 높이를 바꾸므로 Stand 함수만 수정해서는 안 된다.
- **35°/70°:** 효율 탐색 후보로 남김. 현재보다 몸체가 높고 기본 조건의 최대 기울기가 더 커서 첫 실기 후보로 고르지 않았다.
- 완전 신전 자세나 더 큰 보폭·더 빠른 주기로 확대하는 것은 이번 결론에 포함하지 않는다.
- 실제 로봇에는 자세 변경을 하지 않았다. 로봇에 연결하지 않고 시뮬레이션만 진행했다. 새 배터리를 이용한 실험은 과방전 보호 및 안전한 정지 대책을 먼저 확인해야 한다.

## 비교 방법

새 STEP 모델, 12축 토크 구동, 추정 질량 4.398 kg, 11.1V 3S, 접촉·마찰·전압 강하·모터 토크/속도 제한 사용. 기본 Stand에서 2초 안정화 → 1초 자세 전환 → 1초 안정화 → 20초 전진. 보행 시작 2초 이후의 효율·기울기를 측정했다.

V15 전진 궤적(보폭 1.6배, 기존 2400~1800ms 주기)에서 발 X 위치와 들어 올리는 높이를 보존하고, 명목 다리 길이만 변경했다. equal-link 정규화 IK는 기존 펌웨어 좌표계와 일치하지만 실제 CAD 링크 길이/축/영점은 아직 보정되지 않았다. 표의 J2/J3는 **중립 기준 각도**이며 보행 중 각도는 계속 변한다.

**IMU 자세 보정은 OFF.** 실제 펌웨어의 IMU 필터·안전 복귀·전체 타이밍은 재현하지 않는다. 실제 오른쪽 쏠림 해결 및 전도 방지를 검증한 결과가 아니다.

## 시간 간격 수렴 확인

기존 2ms 물리 간격에서 더 편 자세의 기계적 에너지 결과가 크게 달라졌다. 1ms, 0.5ms, 0.25ms로 줄여 확인했다. 기본 조건의 0.5ms→0.25ms 차이는 속도 약 1% 이내, COT 약 2% 이내였다. 따라서 이번 결론은 **0.5ms 결과**를 사용한다. 2ms에서 나온 '다리를 펴면 에너지가 크게 증가한다'는 초기 해석은 채택하지 않는다. 이는 새 자세의 수치 민감도이며 기존 물성 모델의 실제 정확도를 보증하지 않는다. 방향 편차는 접촉 민감성 때문에 별도 불확실성이 남는다.

## 기본 조건 결과 (0.5ms)

| 중립 J2/J3 | 45°/90° | 40°/80° | 35°/70° |
|---|---:|---:|---:|
| 전진 속도 | 6.04 cm/s | 6.52 cm/s | 6.60 cm/s |
| 기계적 COT, 작을수록 적은 일량 | 0.620 | 0.532 | 0.493 |
| 최대 몸체 기울기 | 1.07° | 2.54° | 3.51° |
| 종료 시 yaw | -3.01° | -1.02° | +3.96° |
| 최대 관절 추종 오차 | 7.76° | 5.96° | 5.34° |
| 접촉 지점 미끄러짐 속도 | 0.00579 m/s | 0.00664 m/s | 0.00657 m/s |
| 정지 후 모델 COM 높이 | 18.19 cm | 19.58 cm | 20.84 cm |
| 정지 후 관절 절대 토크 평균 | 0.573 Nm | 0.539 Nm | 0.501 Nm |

40°/80°는 현재 기준 대비 속도 약 8% 증가, 기계적 COT 약 14% 감소다. COT는 abs(토크×각속도)를 적분해 질량×중력×전진거리로 나눈 지표이며 **배터리 실측 효율이 아니다**. JSON의 전기 에너지 추정치 역시 간이 전류 모델 결과라 사용 시간 예측으로 사용하지 않는다.

## 조건 변경

기본 / 비배터리 질량 +20%, 마찰 .55, 10.8V / 비배터리 질량 -15%, 마찰 1.05, 12.6V / 배터리 위치 이동 및 지연 40ms / 저마찰 .4의 총 5조건을 각 3자세에서 비교했다.

- 15회 모두 전도 및 IK 범위 초과 없음.
- 40°/80°는 5조건 모두 45°/90°보다 빠르고 COT가 작았다.
- 몸체 최대 기울기와 yaw는 모든 조건에서 개선되지 않았다. 무게중심 이동 조건에서는 40°의 yaw가 약 +3°, 45°는 약 0°였다.
- 정지 자세, 전진, 회전 전환, 경사·장애물을 하나의 검증으로 묶지 않는다. 이번 비교는 평면에서의 전진 및 준비 전환에 한정한다.

결과: `simulation/mujoco/gait_search/stance/`의 `refined_validation.json`, `convergence.json`. `coarse_search.json`과 `coarse_validation.json`은 초기 시간 간격 비교 기록이며 최종 순위 자료가 아니다.
