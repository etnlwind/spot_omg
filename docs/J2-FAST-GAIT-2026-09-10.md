# J2 협응 빠른 보행 — 2026-09-10

기존 `joint`를 유지하고 `jointfast` / **J2 협응 · 빠르게**를 추가했다. 기본 프로필 cruise는 유지한다. 앱은 실제 폰 UJIN17만 사용하며, iOS Simulator를 실행하지 않았다.

## 무엇을 바꿨는가

최대 전진의 보폭 파라미터를 65→85mm, 주기를 1.4→1.5초로 조정했다. J2 목표각의 주기 내 가동폭은 약 18.51→23.14°로 증가했다(전진 100%, IMU 보정 전 공유 C 목표 기준). J2가 다리를 더 멀리 보내도록 하면서 J2/J3의 기존 속도 선행 보상 40/10ms 상당 계수와 발높이 명령 15mm를 유지한다. 주기만 급격히 짧게 만든 후보는 흔들림과 앞발 끌림이 커졌다.

저속/제자리 회전/후진에는 이전 joint 파라미터를 사용한다. 전진 입력 0→50% 구간에서 기존 파라미터와 빠른 파라미터를 부드럽게 보간한다. 후진 입력 상한 60% 유지. 모터 토크·속도 한계나 물리 질량은 변경하지 않았다.

약 25% 빠르다. 기본 모델 3개 seed에서 0.107m/s, 기울기 RMS 0.672–0.694°, 최대 1.78–2.33°. 속도는 향상했으나 RMS 기울기는 기존 약 0.408°보다 증가했다. 중간 스윙 구간의 지면 여유 1mm 미만 비율도 약 25.5→43.3%로 증가했다. 주기 최고 발높이가 유지된다는 사실과 발 끌림이 완전히 해소된다는 주장은 다르다.

기계출력은 샘플 시점의 합계 |관절 토크×각속도|이며 배터리 전력이나 효율이 아니다. 정격 토크 초과 노출이 남아 있으며 열적 연속운전은 검증하지 않았다. 모델의 질량·마찰·서보 응답은 여전히 실측 전 추정값이다.
