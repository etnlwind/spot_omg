# V15: 조이스틱 전진 보폭 확대

사용자 요청: 조이스틱 전진이 너무 조금씩 진행하므로 보폭을 키워 효율 개선을 시도한다.

## 구현

- 전진 성분의 발 앞뒤 이동 폭을 **1.6배**로 늘린다. 기존 궤적 중심을 기준으로 발 좌표 X의 진폭을 확장하고 IK로 관절 각도를 계산한다.
- 발 높이, 궤적 중심, 지지 순서, J1 자세, 기존 2400~1800 ms 주기는 유지한다. 단순히 무릎을 더 높이 들어 올리는 방식이 아니다.
- 후진·순수 회전·별도 trot5는 유지한다. 혼합 조이스틱 입력에서는 전진 성분만 확장하며 V14의 회전 입력 ±500 제한을 유지한다.
- C `gait_policy_drive_stride_targets`와 Python 바인딩을 함께 제공한다. `gait_policy_drive_targets`의 기본값이 1.6으로 변경되어 실제 조이스틱 경로에 연결된다.
- IMU 설정 및 기울기 정지 로직은 변경하지 않았다. 실제 조이스틱은 기존 설정에 따라 자세 보정이 적용된다. 이번 수치 비교는 **자세 보정 OFF**로 수행했다.

## 비교

새 STEP 모델, 추정 질량 4.398 kg, 11.1 V 3S 기본 조건. 18개 보폭/주기 조합을 먼저 16초씩 비교하고, 1.6배·기존 주기를 6조건에서 24초씩 검증했다. 별도 회전→전진 12조건도 기존 V14(보폭 1배)와 비교했다.

| 기본 조건 24초 | 기존 | V15 후보 |
|---|---:|---:|
| 정상 구간 전진 속도 | 2.82 cm/s | 5.94 cm/s |
| 이동거리당 기계적 에너지 지표(COT) | 1.051 | 0.642 |
| 접촉 지점 평균 미끄러짐 속도 | 0.00935 m/s | 0.00607 m/s |
| 최대 몸체 기울기(정상 구간) | 2.83° | 1.02° |
| 최대 관절 추종 오차(시작 포함) | 6.95° | 8.33° |
| 정격 토크 초과 비율 | 16.39% | 13.98% |

COT는 합산한 abs(토크×각속도)의 기계적 일량을 질량×중력×전진거리로 나눈 값이다. 실제 전기 소비량이나 배터리 사용 시간 측정이 아니다. 정상 구간은 보행 시작 2초 이후다.

- 6조건 전진 속도: 기존 2.56~3.63 → 후보 4.72~6.42 cm/s. 전도 0/6 대 0/6.
- 회전→전진 전도 0/12 대 0/12, 최대 roll/pitch 기울기 4.56° → 3.68°.
- 무겁고 미끄러운 조건에서는 미끄러짐 0.01195 → 0.02354 m/s, 최대 추종 오차 7.96° → 11.25°로 증가했다. 장점만 있는 변경은 아니다.
- 일부 조건에서는 진행 방향 오차도 증가한다. 실제 로봇의 오른쪽 쏠림이나 이전 전도가 해결됐다는 증거가 아니다.
- 별도 GUI 재생 12초: 전도 없이 전진 약 0.75 m. 이 재생은 준비 시간/시작 위상이 위의 24초 비교와 달라 별도 결과로 취급한다.

원자료: `simulation/mujoco/gait_search/drive_stride/{search,validation,transitions}.json`.
