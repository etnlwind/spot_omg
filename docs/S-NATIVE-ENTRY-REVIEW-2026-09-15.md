# Windows에서 이어서 확인한 V5 출발 분석

기준 커밋: `7111d1e`. 인수인계 문서의 미해결 착지 동기와 전도를 재현했다.
실기 연결 없이 기존 MuJoCo 추정 물리 모델로 실행했다. 총질량 2.754kg,
쿠션 D37.3×27mm, 충돌·서보 제한·명령 지연은 그대로 유지했다.
2초 정지 후 전진 100%, 총 6초를 20ms 관측 간격으로 기록했다.
전도 관찰을 위해 기존 `--allow-fall` 조건을 사용했다.

## 재현과 원인 분리

| 조건 | 첫 RL 접지 | 첫 FR 접지 | 90° 전도 관측 |
|---|---:|---:|---:|
| V5 원본 | 2.46초 | 2.54초 | 3.20초 |
| 주기 지지 보정 제외 | 2.46초 | 2.54초 | 3.20초 |
| J1 오므림 제외, 진단 전용 | 2.46초 | 2.54초 | 4.34초 |

접지는 발 높이가 2mm를 초과하고 하중이 0.1N 미만이 된 뒤 처음 0.5N을
초과하는 관측 프레임이다. 20ms 표본 해상도의 접촉 판정이며 무한 정밀한
충돌 시각은 아니다. 원본 결과는 인수인계의 80ms 차이와 전도 시각을 재현했다.
J1 오므림 제외는 사용자 동작 조건을 위반하는 원인 분리 실험이므로 새 보행
모델로 등록하거나 앱에서 선택할 수 있게 만들지 않았다.

RL이 먼저 닿은 2.46초의 FR−RL 발 최저점 높이 차이:

| 계산 조건 | 차이 |
|---|---:|
| 실제 몸체 자세 + 실제 관절각 | 약 17.97mm |
| 몸체만 수평 + 실제 관절각 | 약 0.39mm |
| 몸체 수평 + 명령 관절각 | 약 0mm |

수평 비교는 별도 MjData로만 계산했다. 실제 시뮬레이션 상태나 제어 입력을
덮어쓰지 않았다. 이 프레임에서 약 17.58mm는 몸체 회전의 기하학적 효과로
설명된다. 당시 roll −2.99°, pitch −1.59°였다. 관절 추종 오차가 전체 동작에서
없다는 뜻은 아니다. 예를 들어 2.40초에는 수평 상태에서도 약 4.05mm 차이가 있다.

두 격리 시험 모두 첫 착지 차이를 해소하지 못했다. 따라서 첫 FR J1 오므림이나
정상 보행의 주기 지지 보정 하나만을 80ms 차이의 원인으로 단정할 수 없다.
J1을 고정하면 전도가 늦어지지만 여전히 넘어지므로 안정성 해결도 아니다.
현재 증거만으로 V6를 기본 모델로 승격할 근거는 없다. V5 동작은 보존했다.

## 다음 보행 실험의 기준

첫 스윙 후반(2.30~2.46초)에 몸체 회전이 커지는 원인을 지지발 FL/RR의
반력과 몸체 각운동량으로 확인한다. 두 번째 걸음에서는 비대칭 발 배치와
지지발 J1 전환까지 포함한 과도 구간의 힘/모멘트 예측을 검토한다.
개별 발 높이를 임의로 엇갈리게 해 목표 동기를 깨거나 충돌을 꺼서 맞추지 않는다.
새 제어 후보는 V6 등 별도 이름으로 추가하고, 첫 접지 차이·전도·정지 복귀를
동일 조건에서 함께 비교해야 한다.

## 도구와 검증

```powershell
python simulation/mujoco/scripts/analysis/diagnose_s_native_entry.py --output artifacts/s-native-v5/windows-entry-2026-09-15
```

원시 기록은 위 폴더의 `v5.json`, `support-off.json`, `j1-fixed-isolation.json`이다.
각 프레임에 몸체 자세, 실제/명령 관절각, 원래/수평 몸체의 발 높이, 접촉 하중을 저장한다.

Windows 앱에는 S-native V5~V1 목록, 시뮬레이터 전용/개별 capability 검사,
초기 상태 확인 후 지원되는 최신 버전 선택을 추가했다. Stow 호스트 검사와
삼각형 간격 검사의 출력 경로는 `artifacts/simulation/mujoco/diagnostics/stow/`로 수정했다.
Windows 및 S-native/기본 모델 호스트 검사 58개 통과. Stow encoder 검사도
출력 파일 생성까지 통과했다. FCL 삼각형 간격 검사는 이번에 재실행하지 않았다.
실기 설정 readback, 실제 위치 유지, 전체 실기 동작 시험은 수행하지 않았다.
