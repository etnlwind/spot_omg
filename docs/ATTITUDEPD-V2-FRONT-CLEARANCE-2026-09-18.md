# IMU 자세 안정화 V2: 앞발 들림 시험

사용자 관찰: attitudepd 전진에서 뒷다리는 양호하지만 앞발 들림이 낮다.
원본 attitudepd를 보존하고 attitudepd_v2를 추가했다. 실기 설치 전 시험 버전이며 개선 완료가 아니다.

## 변경

- 전진 중 FL/FR 스윙에만 CAD 발 높이를 최대 4mm 추가한다. 전진 입력 0~0.5에서 매끄럽게 증가하며 시작 진폭도 반영한다.
- 스윙 시작/끝에서 위치·속도·가속도가 0인 높이 곡선을 사용한다. XY 목표, 위상, 지지 여부를 보존한다.
- 정상 진폭에서 RL/RR 목표는 원본과 정확히 같다. 앞다리도 지지 중과 후진에서는 원본 목표를 유지한다.
- 시작 진폭 0은 공용 S 자세이며, 출발 때 원래 보행으로 매끄럽게 전환한다. 따라서 출발 전환 구간은 원본과 다르다.
- 원본 PD 이득, IMU 축 검증 보호, 관절 영점·부호, 서보 제한, 충돌/기울기 보호는 그대로다.
- 펌웨어 인덱스 0~23을 보존하고 V2를 24에 추가했다. 앱 목록 최상단 및 지원 capability 연결의 기본 선택, 시뮬레이터 기본 모델을 갱신했다.
- 원본은 그대로 선택 가능하다. 새 capability 없는 현재 실기 펌웨어에서는 V2를 선택할 수 없다.

## 검증

공유 C 비교에서 직진 원본의 대각선 4,020쌍은 관절 목표 차이 0도, J2 축 기준 CAD X/Z 차이 최대 약 0.00012mm였다. 사용자가 관찰한 실제 들림 차이는 단순 목표 복사로 해결되지 않는다.

호스트 회귀는 앞발 추가 높이, XY 보존, 뒷다리/지지 목표 보존, S 출발, PD/통신을 검사했다. 앱·ARM 빌드를 수행했다. 자세한 결과는 `artifacts/attitudepd-v2/`에 있다.

동일 추정 물성의 16초 MuJoCo 시험(10초부터 전진, PD OFF)에서 아래 값을 얻었다. 발 높이는 12~16초의 실제 물리 바닥 여유 최대값이며 목표 높이가 아니다. 짧은 비교이며 접지 동기나 전체 동작 합격 판정이 아니다.

| 후보 | FL / FR 최고 여유 mm | RL / RR 최고 여유 mm | roll RMS ° (10~16초) |
|---|---|---|---|
| 원본 | 4.65 / 4.80 | 26.35 / 26.72 | 2.19 |
| V2 +4mm | 6.50 / 3.72 | 30.31 / 30.95 | 2.85 |
| +10mm (채택 안 함) | 8.94 / 4.19 | 36.59 / 36.55 | 3.94 |
| +8mm 이른 들림 (채택 안 함) | 8.80 / 4.19 | 38.08 / 37.89 | 4.06 |

모든 후보는 이 짧은 구간에서 안전 중단은 없었으나, 양쪽 앞발 개선 및 흔들림 개선은 입증하지 못했다. 높이 증가만으로 충분하다고 결론내릴 수 없다. 뒷다리의 명령 보존이 실제 뒷발 궤적 보존을 보장하지도 않는다. +4mm는 개선 성공 모델이 아니라 후속 추종·하중 분석을 위한 제한된 시험 버전이다.

실기 설정 readback, 위치 유지 시험, 전체 보행은 수행하지 않았다. 펌웨어나 앱 설치도 이번 작업에서는 수행하지 않았다. IMU body 축 검증값은 0을 유지한다. 실기 업데이트는 Landing 실제 도착 확인 후 토크 OFF 절차를 따른다.

## 사용자 요청 실기 8걸음 시험 (2026-09-18, 후속)

사용자가 실제 로봇에서 8걸음 시험을 명시했다. Landing 완료(오차5틱)와 12개 토크OFF readback 후 `attitudepd-v2-v78`을 설치했다. SHA-256 `d484d13512e8e247f3e6a6ebc8c7a4459808b8c1c540c33a62e9a374c6066cdf`, 321532바이트. 설치 후 Landing 재완료와 12개 영구 레지스터 보존을 확인했다.

전용 `gaitsteps 8`은 V2에서만 허용한다. 정상 목표 위상의 반주기 경계 8회를 센 뒤 추가 스윙 없이 자세 복귀로 전환한다. 외부 heartbeat/watchdog 및 기존 보호는 유지하며 20초 상한을 둔다. 호스트 검사는 10~60ms 프레임에서 여덟 번째 목표를 명령한 다음 복귀하는지 확인했다. 이 계수는 실제 접촉 센서의 걸음 수가 아니다.

첫 준비 실행은 스크립트에 남은 V625 모델명 검사로 움직임 전에 중단했다. 해당 검사만 바로잡고 실제 보행은 한 번 수행했다.

- `$SPOTDRIVE stopped reason=ok elapsed=7466ms`.
- `$GAITSTEPS` 종료 출력은 수신 기록에서 확인되지 않았다. 전체 IMU 기록 374개에서 위상 반주기 경계가 정확히 8회임을 독립 확인했다.
- IMU 최대 절대 roll5.1°, pitch2.1°. 관절 링버퍼256표본 수집/검증 완료. 실제 발높이와 접지 동기 검증은 미완료.
- FL J3 RMS 추종오차6.94°, FR J3 5.61°. 뒤 J3는5.56°/5.66°. 240ms 조회 간격의 자료이며 토크 부족 원인 판정은 아니다.
- 별도 `baldiag`/`gaitdiag` 조회는 본문 수신 후 prompt timeout. 보행 정상 종료와 검증된 joint/IMU 다운로드는 별도다.
- 종료 후 Landing 완료(오차12틱)를 확인하고 Relax. 최종 Landing·torqueOFF·safetyOK. 토크OFF 이후 목표 대비 오차는80틱으로 증가했다. 토크OFF 상태를 위치 유지 합격으로 해석하지 않는다.
- 독립 정지 위치 유지 시험이나 개선 전후 실기 발높이 비교는 수행하지 않았다. 앱에는 이번 펌웨어 버전 대응 설치를 수행하지 않았다.

기록: `artifacts/attitudepd-v2/hardware-eight-steps/`, 위상 검증 `trial-02/eight-step-phase-verification.json`, 관절 분석 `trial-02/joint-analysis/report.md`.

사용자는 실기 시험 직후 “방금 보행을 잘했어 괜찮은데?”라고 평가했다. 이번 8걸음의 사용자 관찰은 양호로 기록하며 앞발 +4mm를 유지한다. 반복 보행·회전·독립 발높이 측정까지 검증된 것은 아니다.

## iPhone 후속 업데이트

사용자 요청으로 iPhone UJIN17에 앱 V0.5.0(48)을 설치했다. V2 목록/지원 판별과 V78의 기존 직접 설정 보행·간격 설정 호환성을 포함한다. iPhone 빌드 및 설치 버전 조회를 확인했으며, 관련 Swift 호스트 검사2개와 Windows 프로토콜 검사49개가 통과했다. 이 업데이트를 위해 보행을 추가 실행하지 않았다.
