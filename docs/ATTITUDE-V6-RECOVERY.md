# IMU 자세 안정화 V6 — 복귀 발들림 개선 (V92)

2026-09-22: 사용자는 V5 전진에서 네 발 모두 복귀 중 바닥을 끈다고 보고했다. 사용자 보행의 Mac 로그에서 네 J3의 최대 목표/실측 차이 14.5~17.1°를 확인했다. J3 미사용이 아니라 궤적 추종 문제를 개선하는 작업이다. [진단 기록](../artifacts/attitudepd-v5/j3-recovery-diagnosis/OBSERVATIONS.md).

## 적용한 동작

- 새 `attitudepd_v6`를 인덱스 28에 추가했다. V5(27)와 기존 프로필의 순서·동작을 보존한다. 지원되는 앱 연결과 시뮬레이터의 기본 모델은 V6다.
- 이 모델은 기존 IMU 자세 안정화 V5의 보완이다. 사용자가 선택한 **Stand B**, 보폭, 대각선 위상, 기본 발높이와 추가 발높이 저장값을 유지한다. 과거 S-native V6와 별개다. 대기 자세나 서보 원점·방향·Landing 기준을 바꾸지 않았다.
- 전진 시 복귀의 첫 18%는 평면 궤적의 뒤쪽 X를 유지하며 발을 들어 올린다. 중간 64%에서 앞으로 가져오고, 마지막 18%는 앞쪽 X를 유지하며 내린다. 실제 CAD 쿠션 X에는 관절·쿠션 형상의 작은 차이가 있으므로 완벽한 수직 이동이라고 표현하지 않는다.
- 기본 높이 곡선은 앞 40%에서 상승, 중간 20%에서 높이 유지, 마지막 40%에서 하강한다. J2/J3를 함께 IK로 계산한다. 추가 발높이는 기존 CAD 수직 보정으로 계속 적용되며, 조용히 줄이거나 무시하지 않는다.
- 지지 구간은 앞뒤 20%를 C2 속도 램프로 바꾸고 중간 60%에서 민다. 발을 떼거나 내려놓는 경계에서 수평 속도·가속도가 0으로 이어진다. 앞쪽 이동·회전 혼합도 같은 궤적 진행량을 쓴다.
- 전진 주기를 V5의 1.25배로 늘렸다. 최대 입력에서 **주기 0.808→1.010초, 복귀 0.388→0.485초**다. 중간 밀기 속도는 V5와 같지만 **지지 구간 평균 목표 속도는 20% 낮다**. 주기만 줄였던 V5의 추종 부담을 낮추기 위한 명시적 절충이다.
- 전진 시작 진폭은 2초에 걸쳐 올라간다. 명령 처리나 위상 진행을 멈추는 대기는 아니다. 역방향·순수 제자리 회전의 궤적·주기·1초 시작 램프와 기존 모든 모델은 유지한다. 낮은 양의 입력에서 새 동작으로 부드럽게 섞인다.
- 펌웨어 및 시뮬레이터 drive/simwalk와 추가 발높이가 동일한 C 시작 배율과 주기를 쓴다. IMU·기울기·위치 보호, 서보 속도·가속도·토크 설정은 바꾸지 않았다.

## 검증 결과와 한계

### 호스트 명령·서보 프로필 모델

소프트웨어 관절 범위·IK·서보 변환·경계 연속성과 시작/정지/방향 전환을 검사했다. 이전 프로필 회귀도 수행했다. STS 프로필 비교에는 기존 속도/가속도 제한을 사용한다. 관측된 `match_age`를 실제 지연 시간으로 튜닝하지 않았다.

최종 정상상태 비교에서 최대 전진·추가높이 0의 J3 모델 최대 추종오차가 14.33→10.90°, 복귀 중앙의 최소 높이 지표가 2.42→6.39mm로 개선됐다. 이는 하중이나 바닥 접촉을 포함하지 않는 내부 기준 모델이며, 높이 지표는 실제 바닥에서 측정한 여유 높이가 아니다. 최종 수치는 [프로필 검증 보고서](../artifacts/attitudepd-v6/final-profile-validation/REPORT.md)에 기록했다.

기존 펌웨어·발높이 회귀 118개, 최종 V6 명령·시뮬레이터 연결 검사 21개를 통과했다. 후진·회전 3,030개 입력/위상 조합에서 V5/V6 목표와 주기가 정확히 일치했다. 시뮬레이터 명령 경로 단위 검사는 물리 엔진을 대체하므로, 아래의 접지 시뮬레이션과 별도 검증이다. 프로필·앱 표시 생성 파일 검사와 `git diff --check`도 통과했다.

### 추정 물리 시뮬레이션

기존 2.754kg 모델, 모터/가속도 제한, 충돌과 보호를 유지했다. 기본 비교는 balance/heading OFF, 보행 8초 뒤 정상 정지를 요청했다. 값은 실기 속도나 실제 발높이 측정이 아니다.

| 조건 | V5 | V6 | 해석 |
|---|---:|---:|---|
| 최대 전진, 추가높이 0, 몸체 전진 속도 | 0.156m/s | 약 0.175m/s | 같은 추정 물리 모델 |
| 같은 조건, 최대 관절 추종오차 | 16.9° | 약 11.5° | 전체 관절 최대값 |
| 같은 조건, 복귀 중앙 FL/FR 하중 접촉 비율 | 94% / 92% | 약 30% / 39% | 끌림 감소, 완전 제거 아님 |
| 같은 조건, 복귀 중앙 RL/RR 하중 접촉 비율 | 79% / 81% | 약 24% / 25% | 동일 |
| 반 스틱, 추가높이 0, 전진 속도 | 0.084m/s | 약 0.060m/s | 발들림·추종 개선과 속도의 절충 |

추가높이 0에서 최대/반 스틱 전진·정지를 완료했다. IMU 자세/방향 보정 ON 최대 전진, 좌우 혼합 전진, 후진의 추가 시험도 완료했다. NumPy matmul 경고는 남아 있고 결과 CSV의 모든 수치가 유한한지 별도로 확인했다.

**앞발에만 +30mm인 비대칭 조건은 아직 충분히 안정적이지 않다.** 최대 전진·정지는 완료했지만 추종오차가 약 28.8°였고, 반 스틱에서는 시작 후 약 2.76초에 기울기 보호로 중단됐다. 이 설정에서 안정 보행을 검증했다고 표시하지 않는다. 보호를 끄거나 설정값을 축소해 시험을 통과시키지 않았다.
