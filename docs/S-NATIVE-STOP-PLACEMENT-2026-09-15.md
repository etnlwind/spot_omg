# V6.1 정상 정지: 제자리 두 걸음

사용자 요청: “정지신호가 떨어지면 제자리에서 하나, 둘 걸음 걸으면서 맞추는 거지.”
각 대각선 쌍이 다음 발 옮김에서 S에 도착하도록 변경했다. 보행 모델은
`s_native_v6_1`이며, 펌웨어 소스 리비전은 `s-native-v6-1-v62`다.
새 보행 모델 V6.2의 후방 밀기 확대 작업과 구별한다.

## 목표 동작

정지 시 마지막 목표 자세와 발 위치를 저장하고 전진·회전 목표를 더 진행하지 않는다.
현재 스윙 위상의 대각선 쌍을 먼저, 반대 쌍을 두 번째로 옮긴다.
각 쌍의 0.6초 구간은 다음과 같다.

| 구간 | 해당 쌍의 목표 | 반대 쌍 |
|---|---|---|
| 0~0.12초 | J1/X 유지, S 바닥 기준 최대 12mm 들기 | 이전 목표 유지 |
| 0.12~0.24초 | 한 번의 옮김으로 X와 J1을 S 목표에 맞춤 | 이전 목표 유지 |
| 0.24~0.27초 | 옮긴 위치 유지 | 이전 목표 유지 |
| 0.27~0.42초 | X/J1 유지하며 내리기 | 이전 목표 유지 |
| 0.42~0.60초 | 정확한 S 목표를 유지하며 지지 | 이전 목표 유지 |

두 번째 쌍도 같은 순서로 진행한다. 전체 1.2초 뒤에는 네 다리 목표가 S다.
기존 완료 응답 전 1초 구간도 S에서 S로 유지하므로 별도 벌림 명령이 없다.
시작 직후 정지, 반복 Stop에도 같은 정상 종료를 사용한다.
비상 중단/보호 중단은 기존 경로를 유지한다.

Python 가상 로봇과 STM32 C 커널에 같은 궤적을 반영했다. Windows/iOS의
기존 정상 `@S` 명령으로 동작하며 추가 버튼이나 모델 선택은 필요 없다.
이전 V5/V6 모델의 정지 정의, 정상 보행, 앞 J1 모터 변환은 보존했다.

## 검증과 남은 접지 문제

- 호스트 회귀 63개 통과: Python/C 목표 및 모터 범위, 출발/정지, 회전 방향,
  방향 유지, 앱 Stop 완료 대기. 기존 1초 종료 가정 1건은 1.2초 두 걸음과
  후속 S 유지 시간에 맞춰 수정 후 재검증했다.
- 별도 물리 정지 8조건: 입력 473/1000 각각 보행 0.04/0.3/1.2/8초 뒤 Stop.
  전부 `safety=ok`, 정상 완료, S 목표 오차 0°, 실제 관절 오차 최대 0.992° 미만.
  정지 중 최대 기울기 4.881°, 정지 후 순수평 변위 최대 약 20.8mm.
  제자리 목표가 몸체의 관성 이동까지 0으로 만든다는 뜻은 아니다.
- **실제 접지 동기는 완료되지 않았다.** 목표 J1이 20ms에 0.05° 넘게 변하는 동안 해당 발의
  바닥 하중이 0.5N 미만인지 별도 측정했다. 8조건 중 3조건은 만족하지 않는다.
  입력 473·8초 정지에서 최대 8.206N, 입력 1000·1.2초에서 8.485N,
  입력 1000·8초에서 1.329N이다. 명령상 발 들기와 물리적 이륙은 구별해야 한다.
  따라서 “발이 완전히 뜬 상태에서만 벌어진다” 또는 “실기 정지 검증 완료”로
  보고하지 않는다. 접지 보정은 후속 과제다.
- 정지 발 들기를 18~30mm로 늘린 후보도 확인했으나 일부 조건에서 기울기
  보호 또는 넘어짐이 발생해 채택하지 않았다. 충돌·보호 기준은 완화하지 않았다.

최종 기록은 `artifacts/s-native-v6-1/stop-placement-v62/final-physical/`에 있다.
`candidates/`, `physical-24mm/`, 초기 `video/`는 미채택 실험이며 최종 영상은
`final-video/`다. 최종 영상은 2초 대기 + 8초 보행 + 4초 정지/유지,
앞·뒤·위·옆 4개 시점이 같은 물리 상태를 표시한다. 10초에 정지한다.

## 펌웨어와 실제 로봇

최종 빌드: `artifacts/s-native-v6-1/firmware-v62-final/s-native-v6-1-v62.bin`,
307196바이트.
SHA256: `6135f9cf8589b1414e3dfd4c62f1130ceaa536c160cc06174dd5e383f6803a29`.
같은 폴더의 `manifest.json`에 부트 벡터/빌드 기록이 있다.
`firmware-v62/`는 이전 중간 궤적의 빌드이므로 사용하지 않는다.

실제 로봇의 마지막 설치 버전은 v60이다. v62 설치, 설정 readback,
위치 유지 시험, 실제 보행·두 걸음 정지 시험은 수행하지 않았다.
현재 작업에서 로봇으로 동작 명령을 보내지 않았다.

재현:

```powershell
$env:PYTHONUTF8='1'
python -X utf8 -m pytest simulation/mujoco/tests/test_s_native_gait.py simulation/mujoco/tests/test_s_native_firmware.py apps/windows/tests/test_stop_return_simulation.py -q
python -X utf8 simulation/mujoco/scripts/validation/validate_s_native_stop.py --output artifacts/s-native-v6-1/stop-placement-check
```

물리 검사 스크립트는 정상 완료/S 복귀를 assert하고, 더 엄격한 접지 기준은
`unloaded_during_j1_command`로 따로 보고한다. 이를 정상 완료 결과와 혼동하지 않는다.
