# V10 왼발 선행 한 걸음: J1 착지 수용 탐색

## 결론

2026-09-22 MuJoCo 48조건에서 **채택 가능한 최적값을 찾지 못했다.**
보호정지 없이 종료한 32조건도 정상 한 걸음으로 판정하지 않는다.
48조건 모두 예정된 왼발 스윙 구간에서 FL/RL 동시 이륙 기준을 만족하지 못했다.
14조건에서는 오른발 회수 이후 왼발이 뒤늦게 들렸다. 이것은 순서 불일치다.
한정된 탐색 결과이며, 이 방식의 불가능성이나 실제 하드웨어 한계의 증거가 아니다.

## 확정한 사용자 요청

1. 오른쪽으로 먼저 기울이는 준비 동작은 하지 않는다.
2. FL/RL을 접어 들고 J1으로 왼쪽 바깥에 내딛는다. 그동안 FR/RR J1이 몸체를 왼쪽으로 민다.
3. 왼발 착지 이후 오른발은 추가로 밀지 않는다.
4. 왼발 J1이 남은 몸체 이동을 받아주고, FR/RR은 J2/J3를 접어 들어 Stand 위치로 회수한다.
5. 여기까지 한 걸음이며 반복하지 않는다. 오른쪽 미러링과 실기 적용은 아직 하지 않는다.

## 구현·검증 수준

- 공유 C 궤적에 오른발 회수와 최종 Stand 유지, 왼발 착지 후 J1 수용 구간을 추가했다.
- 오른발 Y 목표는 밀기 종료 후 들림 초기까지 유지한다. 이후 공중 회수 목표로 돌아온다.
- C 호스트에 명시적인 실험 파라미터 함수를 추가했다. 오프라인 설정은 결과 JSON에 함께 기록된다.
- **현재 전환은 위상 기반이다. 실제 이륙/착지 확인으로 전환하는 제어기는 아직 없다.**
  예정 착지를 실제 착지로 간주하면 안 된다. 접지 로그로 결과를 별도 판정한다.
- J1 수용도 위치 궤적이다. 힘/속도 피드백으로 감쇠력을 제어하는 임피던스 제어를 구현했다고 해석하면 안 된다.
- 물리·충돌·보호 기준과 저장된 사용자 보정값을 완화하거나 바꾸지 않았다.
- 기하/기존 V7–V9 회귀 시험 42개 통과. 동역학 한 걸음 성공은 0건.
- 펌웨어 빌드/장치 설치/실기 움직임 시험은 이번 탐색 범위에 없다. 앱은 업데이트하지 않았다.

## 탐색 범위와 판정

총 48조건: 보폭20/30/40mm, 총 들림30/35/55mm(저장 보정10mm 포함),
한쪽 스윙200/300/450ms, 착지 전 몸체 이동 비율25/50/75%,
착지 후 수용 시간100/250/400ms, J3 대비 J2 시작 지연0–90ms 조합.
완전한 전수 조합은 아니며 재현 가능한 두 묶음의 제한된 탐색이다.
질량2.754kg, 발높이 보정[10,10,10,10]mm, 간격[0,0,0,0]mm.
구동 물성은 현재 시뮬레이터의 추정값이다.

합격 조건: 예정된 왼발 스윙에서 두 발 모두 지면 간격>2mm·하중<0.5N을
최소2샘플(40ms) 만족하고, 왼발 착지 후 오른발 회수·착지를 완료해야 한다.
보호정지 없음, 순 왼쪽 이동>5mm, 앞뒤 오차<10mm, 최대 roll<10°,
오른발 지지 중 미끄러짐<10mm, 마지막 Stand 관절 오차<2°도 요구했다.
이 기준은 이번 비교용이며 실기 안전 인증 기준이 아니다.

대표 `catch-search-02/case-00`:
- 3.66초: 왼발 J3 목표 약110°, 실제 약92°. FL/RL 하중3.24/3.38N으로 접지가 남아 있다.
- 3.76초: 예정 착지 위상0.08에 이미 도달했지만 FL/RL 하중7.98/7.46N.
  목표를 접는 것과 실제 발을 들어 옮기는 것이 일치하지 않는다.
- 3.86초: 오른발이 떠 있고 몸체 roll−8.31°. 왼발 선행 한 걸음이 성립하지 않았다.
- 4.16초: FL/RL이 뒤늦게 들리고 roll+9.35°. 이를 정상 왼발 스윙으로 계산하지 않는다.
- 종료 순 이동: X−71.8mm, Y−16.3mm. 넘어지지 않았어도 실패다.

초기 `results.json`은 늦은 이륙도 집계한 중간 판정이다. **최종 판정은
`validated-results.json`을 사용한다.** 원시 궤적은 그대로 보존했다.
소스 해시는 navigation_control/lateral_instep/drive_control 헤더를 함께 포함한다.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONPATH='.;tools/servo_tool;apps/windows'
python scripts/analysis/optimize_v10_one_step.py --output artifacts/navigation-v10/new-search
python scripts/analysis/optimize_v10_one_step.py --output artifacts/navigation-v10/new-fold-search --fold-lead
python scripts/analysis/optimize_v10_one_step.py --output artifacts/navigation-v10/new-search --reassess
```

다음 과제는 수용 각도 하나를 더 조정하는 것이 아니라, 실제 왼발 이륙을 확인한 뒤
내딛기·착지·오른발 회수로 넘어가는 전환과 J2/J3 실제 응답을 맞추는 것이다.
그 전까지 특정 J1 수용값을 검증된 최적값으로 배포하지 않는다.
