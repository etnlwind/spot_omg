# V6.2.4: 사진 기준 자세와 실측 추종

## 사용자 기준 재확인

사용자가 이미 제공한 사진의 해석은 [V6.2 기록](S-NATIVE-V62-2026-09-15.md)에 남아 있다. **뒤로 뻗었을 때 무릎 아래 링크와 바닥이 거의 수직**이어야 한다. 무릎 안쪽각90°나 서보J3=90°가 아니다. 사진 원본을 현재 다시 열어 본 것은 아니며 기록을 확인했다.

V623 뒤 끝점−135mm 확대 후에도 실제 J2 약60°, J3최소약84°로 충분히 도달하지 못했다. 처음 작성한−160mm V624 초안은 이 기준 재확인 후 교체했고 실기에 설치하지 않았다.

## 구현

- V624는−125mm/+20mm 궤적에서 아래 링크와 바닥의 약89.8° CAD 목표를 사용한다. 실물 도달각의 증명과는 구분한다.
- V623의 부드러운12mm 발 들기와 기준1초, Stop1.6초를 유지한다. 실제 주기는 추종 상태에 따라 길어질 수 있다. 최고 속도3400/가속254는 유지하지만 같은 실제 속도를 보장하지 않는다.
- 기존 `gait_tracking` 감독을 V624 부팅/모델 선택 때 기본으로 켠다. 오차6°이하는 전속 위상, 6~14°는 느리게,14°이상은 공통위상을 일시 정지한다. 낡은 피드백/지속 추종 실패 보호와 Stop 우선 처리는 기존 구현 그대로다. 두 대각선에 서로 다른 위상을 주지 않는다.
- 모델 전환으로 이전 모델을 선택하면 이 기본 감독을 해제한다. 기존 수동 tracking on/off 기능은 유지.
- Python native 동작 경로에도 실제 펌웨어와 같은 추종 감독·시간 진행·오류 정지를 연결했다. 이전에는 비native 경로에만 적용돼 native 감독 비교에 누락이 있었다.
- 지지 표는 V623 것을 명시적으로 공유한다. 발 궤적과 지지 역학을 모두 재최적화한 바닥 보행 모델이 아니다.
- 독립 모델인덱스20, 앱 최상단/지원 연결 기본, 시뮬레이터 기본. V621/622/623과 기존 프로필 인덱스 보존. 펌웨어 `s-native-v6-2-4-v66`.

## 검증

- 호스트77개: 사진 기준 링크각, C/Python 궤적·Stop, 이전 모델 보존, 추종 감독 피드백·시간 경계·오류, Windows 기본 모델/capability 검증.
- 몸체 고정 물리 모델에서 내부충돌0, 보호중단 없음, 최종S 오차0.22°. 순간 추종오차 최대15.54°가 남으며, 정확한 도달 또는 실기 최고속도 유지 통과가 아니다.
- 324692바이트 펌웨어 빌드, SHA256 `6eb84bace5bc8eebc22f63e2c642d765dbb9324f18d09cfd3c900233b5f70769`.
