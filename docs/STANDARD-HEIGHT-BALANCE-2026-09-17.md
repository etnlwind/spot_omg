# 기본 높이와 J1을 유지한 보행: 실패 원인과 검증 상태

2026-09-17. 사용자 조건은 기본 몸체 높이를 낮추지 않고, 첫 두 진입 걸음 이후
정상 J1 각도를 유지하면서 보행 문제를 해결하는 것이다. 이전 45mm 낮춤 후보는
채택하지 않는다. 아래는 MuJoCo 비교 실험이며 앱·등록 프로필·실기 V77에 적용하지 않았다.

## 핵심 진단

현재 부족한 부분은 **발끝 궤적과 몸체의 동적 균형·실제 하중 교대를 함께
계산하는 제어**다. 관절 목표가 도달 가능하다는 것과, 두 발을 띄워도 몸체가
버틸 수 있다는 것은 별도 조건이다. 높이/J1 제한하에서 불가능함을 증명한
것도 아니며, 실제 서보의 물리적 한계를 확인한 결과도 아니다.

1. 기존 V6.2.7 재현은 30초 동안 보호 없이 걷고 S에 복귀했다. 그러나 정상
   구간의 **중간 스윙 표본에서 RL 87.14%, RR 89.02%가 0.5N 초과 접촉**이었다.
   FL/FR은 같은 기준에서 0%다. 의도한 두 발 지지 외에 뒷발의 접촉 지지가
   섞여 있으므로 이 결과를 정상 대각선 보행 성공으로 판정할 수 없다.
   접촉만으로 발의 미끄럼/끌림 속도를 확정하지는 않는다.
2. 큰 회수 동작에서는 두 스윙 발의 접촉력이 모두 0N인 동안 이미 기울기가
   커졌다. 이전 통제 실험의 4.40→4.60초에 roll은 −2.87→−10.54°로 증가했고,
   RL 재접촉은 이후 4.68초였다. 이 실패의 선행 사건은 발 걸림이 아니다.
   기존의 의도치 않은 지지가 사라졌을 때 드러나는 균형 문제가 포함된다.
3. `fr_entry_targets()`는 support Y 목표를 계산하지만 `steady_j1_hold` 경로는
   J1을 정상 각도로 고정하고 `solve_xz()`로 X/Z만 맞춘다. support Y를 0에서
   10mm로 바꿔도 최종 명령은 0° 차이다. J1 고정은 의도한 요구사항이나,
   그 조건에서 기존 좌우 지지 보정을 사용한다고 간주할 수는 없다.
4. 추가한 J2=85°/J3=104°는 스윙 중 회수 목표다. 접지 중 추진력 증가를
   구현·검증한 것이 아니다. 관절각을 크게 만든 뒤 발이 뜨는 동안의 하중
   교대와 몸체 운동이 맞을 것이라고 가정한 접근이 부족했다.

## 기본 높이 유지 실험

`analyze_large_recovery_balance.py`에 `fixed_frame` 제약을 추가했다.
몸체 낮춤, 별도 낮은 정지 자세, J1 변경을 거부한다. 지지 시간 배분과 J2/J3
회수, 기본 높이에서 공통 X 보정을 따로 비교했다. 제약은 **명령 기하**에 대한
것이며 실제 동적 몸체 높이·실제 J1 추종은 별도로 평가한다.

명목 주기 1.8초, 입력 344, 개방 전압 11.1V, 원래 바닥·충돌·기울기 보호·서보
추적 감속을 유지했다. 지지 비율 변경은 각 다리 착지에서만 적용한다.
첫 FR/RL 진입, FR의 두 배 J1 오므림, 다음 FL/RR 진입 후 정상 J1 유지,
두 대각선 배치로 S에 복귀하는 순서를 유지했다.

| 30초 비교 | 최초 보호 시각(2초 대기 포함) | 최대 보행 기울기 | 결과 |
|---|---:|---:|---|
| 기존 궤적, 큰 회수 없음 | 없음 | 5.66° | 뒷발 스윙 중 접촉, 보행 품질 실패 |
| 지지 70%, J2 회수 70° | 13.66초 | 13.09° | 실패 |
| 지지 70%, J2 회수 75° | 11.22초 | 15.69° | 실패 |
| 지지 70%, J2 회수 80° | 9.02초 | 17.44° | 실패 |
| 지지 70%, J2 회수 70° + X 보정 | 없음 | 9.73° | S 복귀, 접촉/높이 품질 미달 |
| 지지 85%, J2 회수 85° + X 보정 | 16.58초 | 보호 후 전도 | 실패 |

X 보정은 CAD 관절 자세와 지연된 IMU 자세/각속도로 지지 대각선과 몸체 중심의
관계를 추정해 공통 발 X를 이동한다. 시뮬레이터의 실제 접촉력이나 몸체 위치를
제어 입력으로 사용하지 않는다. 완전한 동역학 제어나 검증된 접촉 추정기는 아니다.

30초 무보호 X 후보(`x20-short-lead-j270`)의 한계:

- 지지 발의 명령 Z와 정상 J1 목표를 유지한다. 진입 이후 정상 J1 명령의
  변동폭은 네 축 모두 0°다. 실제 J1 변동폭은 약 1.6~2.0°다.
- S에서 몸체 높이 기준은 `cad_base` 질량중심의 바닥 위 232.17mm다.
  진입 이후 entry_phase>=2에서 높이 변화 평균 −2.77mm,
  범위 −14.81~+1.01mm다. **실제 몸체 높이를 일정하게 유지했다고 볼 수 없다.**
- J2 회수 70° 설정에 공통 X 보정이 더해져 실제 최대 J2는 약 68.2°다.
  원한 85° 회수를 달성한 결과로 보고하지 않는다.
- 정상 중간 스윙 접촉 표본 비율은 FL 28.99%, FR 15.56%, RL 8.61%, RR 0%다.
  RR도 최소 발 여유 0.24mm로 2mm 기준에 미달한다. 무전도는 보행 성공이 아니다.
- 정상 구간 평균 위상 속도 계수는 0.789다. 명목 주기는 같아도 추적 보호의
  자동 감속이 있으므로 실제 보행 속도가 기존과 같다고 주장하지 않는다.
- 전진 0.573m, 측면 변위 0.055m, 최종 S 실제 최대 관절 오차 0.99°다.
  정지 도착만 통과했고 전체 보행 품질은 통과하지 않았다.

## 다음 구현이 충족해야 할 것

각도·높이·지지 비율을 독립적으로 늘리는 대신 기본 높이와 정상 J1을 제약으로
두고, 몸체의 자세/각속도, 필요한 지면 반력, 다음 발의 도착 위치·시각을
함께 결정해야 한다. 가능한 궤적 범위에서 접지 중 추진과 공중 회수를 분리하고,
다음 대각선이 실제 하중을 받을 수 있을 때 지지를 넘겨야 한다.

시뮬레이터에서는 접촉력을 기록해 이 조건을 판정할 수 있다. 실기에는 이번
실험과 같은 발별 직접 접촉력 측정이 없으므로 명령 위상만으로 실제 접지를
알았다고 하면 안 된다. IMU·관절 피드백으로 검증 가능한 접촉/추종 상태를
추정하거나 측정을 보완해야 한다. 이것이 곧 H/W 교체가 필요하다는 뜻은 아니다.

  제약 거부 검사, IMU 보정 중 두 지지 쌍의 명령 접지 높이 유지 검사 포함.
