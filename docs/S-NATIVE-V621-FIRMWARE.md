# V6.2.1 실기 이식 — v63

사용자가 V6.2.1을 실제 로봇에도 반영하도록 요청했다. 시뮬레이터의 명목 궤적을
STM32 C 커널로 이식하고, 앱에서 해당 capability를 광고하는 실기에서도 선택하도록 했다.

## 구현과 보존

- 모델 `s_native_v6_2_1`, 펌웨어 `s-native-v6-2-1-v63`.
- 기존 프로필 순서를 유지하여 끝에 인덱스 17로 추가했다. V6.1은 인덱스 16이다.
  V6.2 시뮬레이터 모델과 V6.1 C 지지 테이블/프로필 정의는 보존했다.
- `s_native_reset_profile()`로 상태 초기화 시 모델을 결정한다. 기존 `s_native_reset()`은
  V6.1 동작을 유지한다. CAD 쿠션 기하와 S 기준, 실기 J1 변환은 공유한다.
- V6.2.1의 +20/−125mm, 주기 2초, 교차 감속 제거, 높이 지수 0.25,
  이동 중 무릎 회수와 1.6초 두 걸음 Stop을 이식했다. 후진은 60%로 제한한다.
- Stand, 보행, Stop, idle 유지, 상태 판정 모두 동일한 native 서보 변환을 사용한다.
  FL/FR J1 방향 수정, 저장된 영점/방향, J2 다회전 규약은 바꾸지 않았다.
- STM32 플래시 320KiB에 기존 모델까지 보존하기 위해 새 지지 표만 8차 Fourier
  계수로 저장한다. 추가 표는 7,854바이트이며 입력 변경 시 64개 위상을 복원한다.
  전체 그리드의 복원 오차는 최대 0.319mm다. 최종 관절/서보 목표 비교도 별도로 수행했다.
- watchdog, 20ms 제어, 늦은 프레임·센서·기울기·서보 추종 보호는 유지한다.

## 검증

- 신규/기존 native C, 공용 보행, Windows 프로토콜 검사 **97개 통과**.
- 안전, Stow 서보 좌표, Stow 동작, 자세 감독, 명령 복구의 기존 C 검사 **5개 통과**.
- 전진·후진·회전·복합 입력과 즉시/중간/정상 Stop의 C/Python 비교에서
  V6.2.1 최대 관절 목표 차이 약 **0.0334°**. 실제 보정값을 사용한 서보 범위 검사를 포함한다.
- C 목표를 실제 서보 틱으로 인코딩하고 독립된 실기 축 방향으로 해석하는 MuJoCo 재생:
  전진 100%/47.3%, 후진 60%, 좌우 회전, 복합 입력 모두 보호 중단 없이 S 복귀했다.
  최종 실제 관절 오차는 1.1° 미만이다.
- 최대 전진 8초의 C 재생: X 1.119m, 방향 변화 −0.275°, 보행/정지 최대 기울기 5.419°,
  영상 시각 12.6초에 Stop 완료.
- ARM 빌드: **315,816바이트**, 시작/리셋 벡터와 320KiB 슬롯 한계 확인.
  SHA256 `5a02233bc67be29aebf5c957a7ebc3e58b529c1eea6d034fa9b137e05311d9d6`.

파일:
`artifacts/s-native-v6-2-1/firmware-v63/s-native-v6-2-1-v63.bin`.
검증 근거: `firmware-validation/`, `firmware-host-units/`, `firmware-baseline/`.

## 설치 상태와 실기 검증 수준

설치 전 조회는 기존 `s-native-v6-1-v60`, `torque=on`, `safety=tilt`,
`fault_code=14`, 자세 `custom`이었다. 몸체 지지와 실기 앱 연결 해제를 확인한 뒤
Relax와 토크 OFF readback, `--skip-landing` OTA 순서로 진행한다.
설치 결과는 `artifacts/s-native-v6-2-1/hardware-deployment/`에 별도로 기록한다.

**호스트/시뮬레이터 통과는 실기 위치 유지·보행·정지 검증 완료가 아니다.**
기존 V6.2.1에서 관측한 회수 중 잔여 접촉과 Stop 접지 동기 한계가 남아 있다.
설치와 상태 readback 이후에도 실제 위치 유지와 전체 동작 시험은 별도 단계다.
iOS는 소스만 반영했으며 기기 앱 갱신에는 Mac/Xcode가 필요하다.
