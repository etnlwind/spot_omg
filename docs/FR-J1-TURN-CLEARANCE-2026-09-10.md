# FR J1 우회전 발 끌림 진단 / 후보 비교

초기 비교 당시에는 V34를 사용했다. 최종 V35 설치 결과는 문서 마지막에 기록했다.

**최신 결과:** 초기25/30mm 비교 이후 자세 기준과 전환 속도를 함께 조정한 V35를 빌드했다. 문서 마지막의 최종 결과를 참고한다. 사용자가 전원을 다시 켠 뒤 V35 설치와 재부팅 후 조회까지 완료했다. 실제 회전 주행 확인은 남아 있다.

## 실기 관측

- FR J1 = STS3215 ID4. 2093 → 목표2203/실측2202 이동은 사용자가 **오므리는 방향**이라고 확인했다. 단순 시뮬레이터 축 추정으로 바깥 방향이라고 설명했던 것은 잘못이었다.
- 반대 목표1983/실측1990 이동은 성공했다. 단독 위치 응답 성공은 보행 중 부하 추종 성공을 의미하지 않는다.
- 저장된 gaitdiag: FR J1 최대70틱(6.2°), FR J3 최대79틱(6.9°) 오차. 둘 다 swing 구간이며 과거 목표와의 최소오차 비교상 약120ms 지연에 해당했다. 시간 지연을 직접 측정한 것은 아니다.
- 해당 기록은 마지막 drive 구간의 집계이며 첫 명령은 `drive 177 221 1291`, 종료는 watchdog이었다. 모든 실시간 조이스틱 패킷이나 실제 발 접촉은 기록되어 있지 않다.

## 추정 물리 시뮬레이터 비교

공유 C drive 제어, jointsport, 전진177/우회전221 고정 입력, 14초 실행 중 5–14초 집계. 실제 조작 전체를 정확히 재생한 것은 아니다. 정상 바닥/기존 추정 질량·모터 모델을 사용했다.

기존은 입력 크기에 비례해 들림까지 줄어든다. 후보는 회전 입력0→0.25 사이에서 부드럽게 증가하는 최소 들림 기준을 적용한다. J2/J3는 발 좌표의 역기구학과 기존 선행 보정으로 함께 움직이며 J1 진폭이나 서보 한계를 확대하지 않는다. 시작/정지 진폭은 유지한다.

| 후보 | FR 최대 실제 들림 | FR swing 접촉 비율 | FR swing 중간20–80% 접촉 | 최대 roll/pitch |
|---|---:|---:|---:|---:|
| 기존 |0.083mm|88.3%|81.1%|0.67°|
| 들림 기준25mm |7.46mm|49.2%|34.2%|5.09°|
| 들림 기준30mm |15.01mm|52.5%|32.4%|8.04°|

접촉은 해당 발-바닥 법선력0.2N 초과인 표본 비율이다. 명령25/30mm와 실제 발 높이는 다르다. 이륙/착지 접촉이 포함되므로 swing 전체 비율만으로 실패를 판정하지 않는다. 중간 구간에도 접촉이 상당히 남아 **두 후보 모두 문제 해결 완료로 간주하지 않는다.** 30mm는 흔들림이 더 커서 현재 작업 코드에는25mm 후보를 남겼다. joint/jointfast/jointsport에만 적용되며 yaw=0 직진 궤적은 바뀌지 않는다.

캡처는 세 경우 모두12.16초, FR swing 약49.1% 시점, 동일한 몸체 상대 카메라 각도다. 이 순간 FR 들림은 기존 접촉,25mm 약6.12mm,30mm 접촉이다. 30mm의 가장 높이 든 순간만 선택하지 않았다.

## V35 최종 후보

단순 들림 증가, 빠른 이륙·고도 유지, 크롤 전환, 무게중심 이동, J3 선행 보정 확대 등을 비교했다. 다른 조건에서 기울기 제한 또는 큰 흔들림이 나타난 후보는 제외했다. 일부14초 시험 성공만으로 선택하지 않고34초 회전·전환 시험을 추가했다.

선택된 수정은 **jointsport에만** 적용한다.

- 저속 전진 회전/제자리 회전에서 명령 들림 기준25mm. yaw0→0.25 구간에서 부드럽게 증가한다.
- 회전 자세의 발 좌표 down240mm, x=-10mm로 J2/J3를 함께 조절한다. 다리를 조금 더 세우는 동시에 발의 앞뒤 기준을 재배치한다. 이 값은 실제 지면상의 몸체 높이 측정값이 아니다.
- 전진 입력0.2→0.5, 후진 입력0→-0.2 구간에서 보정 가중치를 연속적으로 줄인다. 고속 전진 회전/후진 회전은 기존 궤적을 사용한다.
- 요청 명령으로 보정 가중치를 정하고 프레임당 최대0.02, 전체 약1초에 걸쳐 전환한다. 속도 램프가 저속 구간을 지나간다는 이유로 잘못된 회전 자세에 잠깐 진입하는 회귀를 방지한다.
- 기존 대각선 위상, J2/J3 선행 시간, J1 방향·센터, 서보 토크/속도 한계, 정지/중단 경로는 유지한다. 최종 구현은 이륙 후 J1 순차 구동을 강제하는 방식이 아니며, 실제 접촉 센서 기반 이륙 확인도 아니다.
- 공유 C drive 상태에 turn_assist를 추가하고 Python/MuJoCo 상태 교환도11 float로 함께 갱신했다.

### 저속 회전 최종 측정

조건은 초기 비교와 동일하다. 아래 접촉 비율은 swing **중간20–80%** 구간의 법선력0.2N 초과 비율이다. 이륙/착지 구간까지 포함한 전체 swing 비율과 혼동하지 않는다.

| 경우 | FL | FR | RL | RR | 최대 roll/pitch |
|---|---:|---:|---:|---:|---:|
| 기존 우회전 |81.1%|81.1%|34.2%|36.1%|0.67°|
| V35 우회전 |0%|3.6%|4.5%|1.0%|1.59°|
| V35 좌회전 |4.1%|0%|0.9%|4.1%|1.52°|

FR 최대 들림은 우회전18.99mm, 좌회전22.59mm다. 우회전 캡처는 초기와 같은12.16초/swing49.1%이며, 그 순간13.53mm다. 접촉이 완전히0이 되는 것은 아니며 실기 재현을 보장하지 않는다.

### 검증과 배포 상태

- 좌/우 각각 제자리 턴, 전진 회전, 턴→전진, 후진 회전 총8개34초 시험 통과. 전도/비발 접촉/중단 없음. 전체 최대순간기울기7.28°.
- 저속 좌·우 발 접촉 회귀, 보정 가중치 전환/고속 회전 진입 회귀, C 최적화 빌드간 전송틱 일치 및 펌웨어 호스트 회귀 **44개 통과**.
- V35 빌드 성공:174256 bytes. SHA256 `1c07ac8712215a00e1102ac0ff769a92db5ac743f36dd4ef8b174d4d2ae7b868`.
- 바이너리 `/private/tmp/spot-turn-v35/shared-locomotion-v35.bin`.
- 사용자가 충전 후 전원을 다시 켠 뒤 BLE 연결 성공. 설치 전12개 서보 응답,11.3–11.5V, torque=off, safety=ok 확인.

- 설치 후12개 서보 응답, hw=0x00, 재시도/실패0 확인. 새 이동 명령은 보내지 않았다. **V35 설치·조회 검증은 완료, 실기 회전 주행 검증은 미완료**다.
