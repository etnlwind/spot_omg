# V52: 중력으로 처진 접힘 자세에서 Landing 복귀

배터리 포함 실측 질량: 2.754 kg (사용자 확인). 이 변경은 물리 모델 질량을 수정하지 않는다.

## 변경

- 기존 공통 접힘 진행률/18도 비교에 추가하여, 양쪽 앞 J2 < -90도 및 양쪽 뒤 J2 < -20도인 유효 관절 배치를 복귀 대상으로 인식한다. 이 임계값은 제한된 회복 분류이며 모든 자세 인식기가 아니다.
- 이 배치에서 Landing은 12초 정리 후 12초 펼침을 수행한다. 정리 중 J2는 현재 위치를 유지하고 J1은 0도로, J3는 각 다리 자신의 J2 접힘 진행률에 해당하는 각도로 이동한다. 더 깊은 Stow 끝점으로 J2를 밀지 않는다.
- 정리 후 12축을 다시 읽어 중간 목표 오차 5도 이내일 때만 펼친다. 두 번째 단계 시작점은 재측정한 위치다.
- 앞 J2의 누적 명령 원점 확인 절차와 관절 범위는 유지한다.
- 펼침 실패에서는 전체 Relax 대신 현재 위치 유지 시도를 한다. 조회/원점 확인 실패 시 유지 성공을 보장하지 않는다. 원점 탐색·모드 변경에 필요한 기존 개별 토크 해제는 남아 있다.
- 펌웨어와 MuJoCo가 동일 C 궤적/분류 함수를 사용한다. 시뮬레이터 역시 준비 단계 추종 확인 후 측정 위치에서 재시작한다.

## 검증

- 호스트 + MuJoCo: 38개 통과. 전원 차단 후 처짐, 모듈로 피드백과 내부 누적 좌표, 비대칭 수동 자세, 정리 단계 J2 유지, Stop/재개 및 기존 왕복 포함.
- ARM 빌드 통과: 251976 bytes, SHA256 c9a125635232a3ec6f9ba6ed96db500ba09e8e936f6e89ce0ae98dcb7433c617.
- 검증 범위: 코드/모형 회귀. 새로운 정리 경로의 모든 CAD 자기접촉·모든 실물 하중 조건을 검증한 것은 아니다. 단일 저전압 샘플 판정 및 40틱 추종 제한 문제는 별도 미해결이다.
- 실기 설치 및 전체 동작 결과는 아래에 별도 기록한다.
