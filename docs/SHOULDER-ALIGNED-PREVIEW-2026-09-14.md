# 어깨 X 정렬 Stand / 보행 시작 비교 영상

실험 전용. 펌웨어 및 배포된 정책은 변경하지 않았다.

기존 쿠션(전체27mm, 원형 외곽37.3mm)을 포함한 CAD에서 각 J1 어깨축의 몸체 기준 X와 쿠션 메시 중심 X를 일치시켰다. Z는 기존 Stand의 쿠션 최저점 평균, Y는 기존 중심을 유지했다. 이 중심은 압력으로 측정한 접촉 중심이 아니다. 정적 IK 결과 네 다리 공통 약 J1=-0.01665°, J2=42.99486°, J3=89.86669°. 기존45/90에서 쿠션 중심은 어깨보다7.3667mm 뒤였다. 기하 잔차 최대0.000062mm.

현재 centerpivot의 계산된 발 궤적에서 현재 속도의 기존 중립 발 위치를 빼고 새 정렬 기준에 더한 뒤 CAD Jacobian IK로 다시 계산했다. 속도별 중립 높이 이동과 출발 전1초 자세 이동을 제거했다. 기존 속도/보폭/스윙 파형/출발 진폭 증가 및 센서 수평 보정은 유지했다. 궤적 IK 최대잔차0.098mm. 관절 목표 최대 프레임 변화2.47°/20ms. 모든 조건의 물리 실현 가능성을 입증한 것은 아니다.

30초 실행: 정지10초, 100%직진20초. 두 카메라는 동일 물리 상태를 같은 프레임에서 렌더링. 1920×540,25fps,750프레임,정확히30초. safety=ok로 끝났으나 최대roll7.90°,pitch5.07°로 수평 유지 개선이 검증된 것은 아니다. 물리 파라미터는 이전 비교 영상과 동일한 추정값이다. 기본자세의 기하 일치가 하중하 실제 위치의 일치를 보장하지 않는다.

## 수정 V2: 사용자가 표시한 어깨는 J2

앞 영상의 J1 기준은 사용자가 표시한 옆면 J2 회전축과 달랐다. J1-J2 X 차이는 약18.9mm. V2는 J2축 기준으로 다시 풀었다: J1 약0.02597°, J2 47.98066°, J3 89.91208°. 기하 잔차0.000354mm지만 동역학 정지8~10초 실제 world-X 잔차는 각 다리 약3.88~3.93mm로 남는다. 명령 기하와 하중하 실제 위치를 혼동하지 않는다.

shoulder-j2-aligned-v2-four-views-idle10-forward20.mp4: 정지10초+전진20초,1920×1080,25fps,750프레임. 같은 실행의 SIDE/TOP/REAR/QUARTER를2×2 동시 렌더링. 앞3개 카메라는 직교투영, 쿼터뷰는 원근투영. SIDE의 빨간선은 J2의 world 수직선이며 텍스트 수치는 FL/FR/RL/RR 실제 쿠션 중심-X 잔차. 네 시점 렌더링 부하로 라이브 창의 벽시계 재생은 느려질 수 있지만 영상은 시뮬레이션 시간기준1배속30초다. 펌웨어에는 적용하지 않았다.

## 높은 발 들림 비교

동일 J2 정렬 기본자세에서 CAD 쿠션 최저점 목표Z를 스윙 구간에32/40mm까지 올리고 기존 plateau 파형·진폭 램프를 유지했다. J2/J3 임의 각도 추가 대신 매 프레임 Jacobian IK로 계산한다. 옆/위/뒤/쿼터뷰 및 고정선/동적 중심점 영상 저장. 정지10초+전진요청20초.

- 40mm: t12.20초(전진 시작2.20초 후) tilt 정지, 이후 전도. 실패 영상 보존.
- 32mm:30초 safety ok였으나 최대roll11.29°,pitch6.88°로 기존보다 불안정. 보행 구간 실제 최저점 최대 지면 여유 FL47.4/FR62.6/RL9.9/RR7.5mm. 최대값은 각기 다른 시점이며 몸체 운동까지 포함하므로 명령 추종 성공을 의미하지 않는다. 뒷발 실제 여유 부족과 앞뒤 비대칭이 남는다.
