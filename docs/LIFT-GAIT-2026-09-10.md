# Lift 보행 비교 모드 — 2026-09-10

기존 전체 설정은 `config/snapshots/locomotion-before-lift-2026-09-10.json`에 보존했다. 기존 cruise와 default는 변경하지 않았다.

새 `lift`는 기존 highstep의 검증된 값을 복제한 독립 비교 프리셋이다. 향후 highstep과 별도로 조정할 수 있다. 크루즈의 주기/보폭을 유지하며 높이만 25mm 또는 14mm로 증가시킨 시안은 회전 중 tilt 정지가 발생해 채택하지 않았다.

| 항목 | 기존 cruise 직진 | lift |
|---|---:|---:|
| 최대 발 들기 명령 | 7mm | 20mm |
| 보폭 파라미터 | 65mm | 45mm |
| 기본 주기 | 0.8초 | 1.05초 |
| 후진 입력 제한 | 100% | 60% |

발 높이는 최대 입력에서의 궤적 명령이며 실제 지면 여유 높이는 자세·접촉에 따라 달라진다. 저속에서는 입력 크기에 비례하여 높이가 감소한다.

## 사용

```bash
cd /Users/etnlwind/project/spot_omg
PYTHONPATH=tools/servo_tool:simulation/mujoco /opt/anaconda3/envs/spot_omg/bin/mjpython simulation/mujoco/virtual_robot.py --viewer --profile lift
```

정지 상태에서 MuJoCo 키 3=cruise, 6=lift. 원격 연결이 없을 때 W=8초 보행, Space=정지. 콘솔 명령은 `gaitprofile lift` / `gaitprofile cruise`.

앱 소스의 보행 선택 목록에 '리프트 · 발 높이 20mm' 추가. 앱 빌드 성공, 실행 중인 앱 교체 설치는 이번 작업에서 하지 않았다. 펌웨어 공유 상수와 모드 인덱스도 추가하여 빌드 성공했으며 실제 로봇에는 설치하지 않았다.

## 검증

- 공유 C 커널·서보 범위·가상 로봇 테스트 33개 통과.
- 명목 추정 물리 조건: 제자리 회전, 전진 회전, 회전→직진, 후진 회전 4개 통과 (`simulation/mujoco/lift_validation.json`).
- 별도 직진→정지 통과, 최대 기울기 6.15도 (`simulation/mujoco/lift_forward_validation.json`).
- 실제 하드웨어 동작 및 다양한 바닥 조건 검증을 의미하지 않는다.
