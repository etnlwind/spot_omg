## 사용 부품과 확인 수준

| 부품 | 반영 내용 | 남은 확인 |
|---|---|---|
| 배터리 | DXF 3S LiPo, 11.1V, 5250mAh, 완충 12.6V | 실제 커넥터: 선택 옵션은 딘스, 대표 사진은 XT90. 실제 제품에 맞는 짝 사용 |
| 충전기 | 판매 설명 12.6V 2A, 5.5×2.1mm | 3S LiPo용 CC/CV 및 충전 종료 기능, DC 극성. 단순 정전압 어댑터와 구분 |
| DALY | 사용자 자료: 3S 12V 60A 하드웨어 BMS | 리튬이온 4.2V/셀 옵션인지 실물 확인. 자료는 리튬철 옵션도 병기. 공통 포트 B−/P−형 기준 |
| PDB | Matek PDB-HEX, 5V 기본 BEC, 서보 전력 분배 | 실제 패드·리비전 및 전류/전압 센서 연결 위치 |
| S1 | 2핀 로커 스위치 | 코일 전류에 적합한 DC 정격 |
| K1 | **JD1914 12V 40A, 5핀 SPDT** | 실물 핀 번호, 접점 DC 부하 정격·돌입 허용, 코일 흡입/유지 전압, 내장 서지 억제 여부 |

이전 사진의 JD1912 24V 제품은 설계에서 제외했다. 새 JD1914에 이전 제품의 ‘내장 다이오드’ 설명을 적용하지 않았다. 소켓 전선 색으로 단자를 추정하지 않는다.

## 전원 연결표

같은 넷 이름은 실제 전기적으로 같은 연결이다. `BAT−`는 원 배터리 음극, `GND_P`는 BMS를 거친 보호 음극이다.

| 시작 | 도착 | 설명 |
|---|---|---|
| 배터리 주 + | F1 입력 | 가능한 배터리 커넥터 가까이에 주 퓨즈 |
| F1 출력 | FUSED+ | 아래 세 분기의 공통 공급 |
| FUSED+ | K1 30 | 고전류 접점 COM |
| K1 87 | PDB IN+ | 코일 ON 시 통전하는 NO, ROBOT+ |
| K1 87a | 연결 안 함 | 코일 OFF 시 30과 연결됨. 소켓 여분 선 끝까지 개별 절연 |
| 배터리 주 − | DALY B− | 모든 부하의 GND로 사용하면 안 됨 |
| DALY P− | GND_P | PDB IN−, 충전기 −, 코일 −, 제어보드 GND |
| FUSED+ | F2 → 충전 잭 + | 릴레이 앞에서 분기하여 OFF 중 충전 가능 |
| 충전 잭 − | GND_P | 별도 C−가 있는 다른 모델이면 충전 −를 C−로 변경 |
| FUSED+ | F3 → S1 → K1 86 | 코일 양극 |
| K1 85 | GND_P | 코일 음극. 실물 억제 다이오드 극성 우선 |
| PDB 주 출력 +/− | 다리별 보호 분기 → 서보 | 네 다리 병렬 전력 배선. 작은 단자 하나에 12축 전류를 몰지 않음 |
| PDB Vx=5V / G | 로직 퓨즈 → MCU·ESP32 | 제어보드의 허용 5V 입력 사용. 3V3/GPIO에 5V 인가 금지 |

BMS B−와 P−를 외부에서 직결하면 보호 기능을 우회한다. 충전기·외부 계측기·USB 등으로 별도 우회 접지가 만들어지지 않도록 전체 배선을 확인한다.

### 셀 감지선

3S 배터리의 밸런스 커넥터를 맞는 연장 하네스로 연결한다. 팩을 해체하거나 파우치 셀에 직접 납땜할 필요가 없다.

| BMS 감지선 | 배터리 연결점 | B0 기준 이상적인 완충 전압 |
|---|---|---:|
| B0 | 첫 셀 − / 팩 − | 0V |
| B1 | 첫 셀 + | 4.2V |
| B2 | 두 번째 셀 + | 8.4V |
| B3 | 세 번째 셀 + / 팩 + | 12.6V |

이는 완충 예시이며 조립 시 실제 전압은 충전 상태에 따라 다르다. **BMS 커넥터를 꽂기 전에** 각 인접 감지선 전압과 순서, 전체 전압을 측정한다. 선 색·커넥터 모양만으로 대응시키지 않는다. 실제 모델의 연결/분리 순서를 따른다. [DALY 공식 결선 설명](https://www.dalybms.com/3s-bms-wiring-tutorial/)

## 대기 소비를 없애는 두 단계

| 상태 | 서보 / MCU / ESP32 / PDB | 릴레이 코일 | BMS | 충전 |
|---|---|---|---|---|
| S1 ON | 켜짐 | 소비 있음 | 연결됨 | 이 설계에서는 충전하며 운전하지 않음 |
| S1 OFF | 꺼짐* | 소비 없음 | 자체 소비 남음 | 가능 |
| 주전원 + 감지선 완전 분리 | 꺼짐 | 꺼짐 | 배터리로부터 전원 없음 | 불가 |

*외부 USB 또는 별도 전원이 연결되어 있으면 로직이 켜질 수 있다.

**배터리에서 외부 회로로 흐르는 전류를 0으로 만드는 방법은 주전원뿐 아니라 BMS 셀 감지선 네 개까지 분리하는 것이다.** 배터리는 자연 방전하므로 배터리 용량 감소 자체가 0이 되는 것은 아니다.

장기 보관용 기본안은 탈착 배터리다. S1 OFF, 충전기와 외부 전원 분리, 해당 DALY 모델의 절차에 따라 감지 하네스와 주전원을 분리한다. 두 커넥터 모두 극성 방지·절연 캡을 사용한다. 주전원만 뽑고 밸런스 선을 남겨두면 완전 분리가 아니다.

원터치 완전 분리도 가능하지만 현재의 로커와 5핀 릴레이 하나로 구현되지 않는다. 고전류 주접점과 다수 감지 접점을 함께 분리하며 BMS에 맞는 순서를 보장하는 전용 커넥터/인터록 구조가 추가로 필요하다. 임의 다극 스위치로 감지선을 제각각 끊는 구조는 채택하지 않는다. 래칭 릴레이만 쓰면 코일 유지 전류는 줄어도 BMS 자체 전류는 남는다.

## DALY 자료가 의미하는 보호 범위

아래는 사용자가 제공한 판매 사양표의 값이며, 실측하거나 개별 제품 설정을 읽어 확인한 값은 아니다.

- 방전 60A 표기, 방전 과전류 보호 180±30A.
- 충전 60A 표기, 충전 과전류 보호 70±10A. **배터리에 60A로 충전해도 된다는 뜻은 아니다.** 이 설계는 2A 충전기를 사용한다.
- 리튬이온 과충전 보호 4.25±0.05V/셀. 정상 충전 목표는 **4.20V/셀**, 팩 12.6V다.
- 리튬이온 과방전 보호 2.7±0.05V 또는 2.8±0.05V/셀. 어느 옵션인지 미확정이며, 두 값 모두 정상 운전 종료 목표로 사용하지 않는다.
- 셀 과충전/과방전 및 충방전 과전류 보호 지연은 표에 1±0.5초로 기재되어 있다.
- ‘수동형 균형’ 항목은 **패시브 밸런싱**을 뜻한다. 리튬이온 기준 약 100±25mA, 시작 전압 4.075~4.175V, 시작 차이 20mV 표기다. 액티브 밸런서로 표현하지 않는다.
- 내저항 단위 `MΩ`, 전류 `MA`, 온도 `-2055` 등은 번역/표기 오류가 의심된다. 이 값을 열설계·온도 안전 한계에 그대로 사용하지 않는다.

**60A BMS는 40A 릴레이와 작은 서보 배선을 대신 보호하지 못한다.** 180A 수준까지 기다리는 과전류 차단을 주 배선 보호로 삼지 않는다. F1과 분기 퓨즈는 전선, 커넥터, 접점, 예상 고장 전류, 시간-전류 곡선에 맞춰 선정한다. 140C 배터리 라벨도 퓨즈 선정 근거가 아니다.

기존의 배터리 운용 경고/종료 정책은 BMS 최종 차단보다 앞서야 한다. 팩 전압만으로 가장 낮은 셀을 알 수 없다. 이 하드웨어 BMS 사진만으로 셀 전압을 STM32가 읽을 통신 기능이 있다고 가정하지 않는다. 셀별 운전 감시가 필요하면 별도 모니터 회로 또는 통신 지원 BMS가 필요하다.

## PDB / 서보 / 제어보드

PDB-HEX 공식 사양은 입력 6~60V, 기본 Vx 5V 연속 5A, 주 전력 분배와 별도의 BEC다. **서보 12개를 5A BEC에서 공급하지 않는다.** 주 출력은 배터리 전압이므로 12V로 안정화된 전원이 아니다. 9V/12V 점퍼로 전체 서보 전압이 바뀌는 것도 아니다. [Matek 공식 사양](https://www.mateksys.com/?portfolio=pdb-hex)

현재 프로젝트의 모터 배치는 J1/J3 STS3215 8개, J2 STS3250 4개다. ST3215 계열에는 12.6V 허용형과 7.4V형이 함께 판매되므로 **실제 장착된 모터의 전압형을 확인한 후에만 3S 직결**한다. 저전압 모터가 섞여 있으면 해당 모터 전력 분기에 충분한 용량의 강압기를 추가하고 원전압 전원과 합치지 않는다. [Waveshare 모델별 전압 표](https://www.waveshare.com/product/modules/motors-servos/st3215-servo.htm)

NUCLEO 외부 5V 입력과 ST-LINK/USB 전원 점퍼는 보드 매뉴얼에 맞춘다. ESP32-WROOM 모듈 자체는 3.3V이므로, 5V 공급은 레귤레이터가 있는 개발보드의 적합한 입력에 한한다. URT-2에는 보드 사양에 맞는 공급을 유지하고 작은 전원 입력/PCB 경로로 전체 서보 전류를 통과시키지 않는다. UART 전압과 반이중 TTL 신호 변환도 구분한다.

PDB의 S1~S6와 Tlm은 ESC용 신호 패드이지 서보 버스 컨트롤러가 아니다. 사용하지 않는다. STM32 USART1 → URT-2 → DATA 버스를 유지한다. ESP32 TX17 → STM32 PC11, ESP32 RX16 ← STM32 PC10은 현재 저장소 문서 기준이다. IMU는 현재 장착된 BNO055/BNO086 보드에 맞는 I²C/SPI 및 전원을 유지한다.

### 향후 전압·전류 계측

Matek 문서에는 Curr의 3.3V ADC 대응·80A/V 환산과 1:21 전압 분압이 기재되어 있다. 다만 `Vbat: Battery voltage` 표기도 병존하므로 **실물에서 원전압 Vbat와 분압 출력 지점을 구분한 뒤** ADC에 연결해야 한다. 연결 전 무부하/기준 부하에서 출력 전압을 측정하고, STM32 ADC 입력 허용 범위·보호·RC 필터·오프셋·게인을 검증한다. 원전압 12.6V를 ADC에 직접 연결하지 않는다. 본 도면에서는 계측선을 연결 보류했다.

## 추가 부품 / 정격 결정

- F1 주 퓨즈·홀더, F2 충전 분기, F3 코일 분기, 로직 및 다리별 퓨즈·홀더. 구체 정격은 부하 전류와 배선 조사 후 확정한다.
- 실제 배터리에 맞는 주전원 커넥터와 3S 밸런스 연장 하네스, 5.5×2.1mm 충전 잭, 단자대 또는 전력 분배 하네스, 압착 단자, 절연 캡과 스트레인 릴리프.
- 코일 서지 억제가 없다면 D1 추가. 예를 들어 코일 전류/에너지가 허용 범위인 경우 1N4007 계열을 검토할 수 있다. 캐소드 띠는 86(+), 애노드는 85(−). 실제 내장 억제 회로가 있으면 그 사양을 따른다. 일반 플라이백 다이오드는 릴레이 해제를 늦출 수 있으므로 안전 정지용 인증 회로라고 부르지 않는다.
- PDB 입력 커패시터는 제조사 제공 부품/지침에 맞춰 극성과 위치를 확인한다. 투입 돌입 전류, 릴레이 접점 손상, 모터 회생 전압도 설치 후 평가한다. 필요하면 프리차지·서지 억제를 추가 설계한다.

12V 코일이 3S 배터리의 전체 운전 범위에서 확실히 붙고 유지되는지는 코일 정격 표기만으로 알 수 없다. 낮은 전압에서 떨림/재투입이 생기면 운전하지 않는다. BMS 차단 후 복구와 S1 ON이 겹칠 때 재통전될 수 있으므로, 결함 발생 후 S1을 OFF하고 원인을 해소한 다음 켠다. 자동 재시작 방지 하드웨어 래치는 이 기본 회로에 포함되지 않았다.

## 조립 후 확인 순서와 검증 수준

1. 무전원: 소켓 단자 번호, NO/NC, 절연, B−/P− 우회 없음, 퓨즈·전선 정격 검토.
2. BMS 미연결: 셀 감지선 순서와 각 셀 전압 확인 후 해당 모델 지침으로 연결.
3. 서보 분리 상태: OFF/ON 시 PDB·5V 출력, 극성, 외부 USB 역급전 확인.
4. 충전만: S1 OFF에서 충전 전압/전류와 셀 전압, 온도 관찰. B3를 동시에 연결하지 않는다.
5. 기체를 안전하게 지지하고 단계별 부하 측정: 다리별 전류, 팩 전압 강하, 배선 발열, 코일 흡입/유지, 전원 재투입 동작 확인.
6. 마지막으로 장기 보관 완전 분리 상태에서 외부 회로로의 공급 경로가 모두 제거됐는지 확인.

현재 완료: 자료 검토, 기능 결선표, 도면 렌더링 확인. **미완료: 실제 전기 연결, 전류·열·충전 시험, 정격 확정 및 실물 동작 검증.**
