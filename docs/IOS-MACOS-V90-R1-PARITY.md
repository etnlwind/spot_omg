# iOS/macOS V90-R1 앱 변경 (2026-09-21)

- 다리별 추가 발 들림은 제어 화면의 ‘발 높이 설정’ 버튼으로 팝업을 연다. FL/FR/RL/RR 입력, 저장·반영, 저장값 불러오기, 모두 0을 제공한다.
- 저장은 설정 명령 이후 새 syncstate 응답과 일치할 때만 완료한다. 저장값은 연결 후 정지 상태에서 한 번 자동 반영한다.
- 보호 정지 사유를 유지하고 새 입력을 직렬 처리한다. 정지 중 새로 누른 입력은 응답 완료까지 보류하며 놓거나 자세 명령을 내리면 폐기한다.
- 배터리 경고는 정지 후 3초 대기, 1초 간격의 세 측정값, 200mV 이하 편차의 중앙값을 사용한다. 과거 보행 최저 전압은 경고 근거로 사용하지 않는다.
- iOS/macOS 기본 다크 테마, 스위치, 보조 글자 대비를 적용한다.
- 앱 릴리스 표기는 펌웨어 기준 V90-R1, 설치 메타데이터는 90.1.0이다. iOS/macOS 빌드 식별자 53은 별도로 유지한다. Windows 버전 표기도 통일했다. 연결된 로봇이 보고하는 실제 revision은 그대로 표시한다.

## 검증

호스트 테스트 78개 통과. 최종 팝업과 버전 변경 후 iOS Simulator 및 Mac Catalyst 화면 테스트 통과, iPhone용 unsigned 빌드 성공, Windows Python 구문 검사 통과. 팝업 iPhone 렌더 이미지를 확인했다.

설정 readback은 주입한 콘솔 응답으로 검증했다. 실기 설정 readback, 실제 위치 유지 시험, 전체 동작 시험은 이번 변경에서 수행하지 않았다. 기기 설치와 로봇 펌웨어 변경도 수행하지 않았다.

로그 및 화면: artifacts/ios-v90-parity/.

## 설치 및 아이콘 복구

Mac 및 iPhone UJIN17에 V90-R1 빌드 54를 설치했다. 원격 V90 교체 과정에서 돌아갔던 구 아이콘을 보존 브랜치의 사용자 지정 주황색 로봇 전면 이미지로 복원했다. 양 플랫폼 서명 빌드 성공 및 설치 완료.

## 발 높이 팝업의 실제 CAD 그림

기존 도형을 MuJoCo CAD 모델의 정지 자세 정사영으로 교체했다. 전방은 위, 좌측 앞발은 FL이다. 주황색 외장과 짙은 회색 관절을 이미지 렌더링에만 적용했으며 시뮬레이터/실기 자세나 좌표는 바꾸지 않았다. 재생성 도구: `scripts/visualization/render_app_robot_top.py`. iOS 화면 테스트 및 양 플랫폼 서명 빌드 통과. 빌드 57 iPhone 및 Mac 설치 완료.
