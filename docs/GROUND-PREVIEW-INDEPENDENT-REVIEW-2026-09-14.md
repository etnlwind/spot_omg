# 지면 기준 보행 후보 독립 검증

대상 설정: `artifacts/audits/sway-2026-09-14/feedforward-iteration4-0.25.json`.
총질량 2.754kg, 주기 3.2초, duty 0.7, 발 전후 이동 매개변수 96mm, 기본 들림 32mm,
시작 램프 4초와 오프라인 roll 사전 보정이 적용된 고정 전진 실험이다.
실물 펌웨어와 앱은 변경하지 않았다. 질량 분포·서보 응답·쿠션 물성은 추정 모델이다.

## 코드 검토

- 런타임 사전 보정은 보행 위상과 고정 계수만 사용한다. 실제 MuJoCo 접촉력/몸체 정답을 런타임 입력으로 읽지 않는다.
- 선택된 설정은 `legacy_balance=true`다. 따라서 CAD 발 궤적을 회전시키고 IK를 푼 뒤 기존 2링크 IMU 보정이 적용된다. 통합 지면 제어기가 완성됐다고 표현하면 안 된다.
- 기본 32mm 들림은 사전 보정 전 수치다. 사전 보정과 실제 관절 추종 이후 앞뒤 발의 높이가 정확히 같다는 의미가 아니다.
- X를 명시적 전진 곡선으로 다시 만들고 foothold 구성요소가 Y를 다시 만든다. 내부 yaw 보정은 이 궤적에 의도된 회전 명령으로 반영되지 않는다. 직진 방향 유지·후진·좌우 턴을 검증했다고 주장할 수 없다.
- 기본 주기 1.35초/duty 0.52에서 3.2초/0.7로 바뀌었다. 이번 개선은 같은 속도에서 얻은 결과가 아니다.
- 별도 `custom_phase`는 고정 간격으로 증가한다. 공용 추종 감시의 속도 조절값을 반영하는 경로는 추가 검증이 필요하다. 현재 기본 실험의 해당 추종 속도 조절은 비활성이다.
- 위치만 일치하는 IK 잔차를 실제 접촉 동기화·토크/속도 실현 가능성으로 해석하면 안 된다. 실제 이륙/착지 시점을 별도 측정해야 한다.

## Stop/재시작 수정

`ground_frame_nominal.py`의 프리뷰에만 다음 처리를 추가했다.

1. 재시작 시 별도 위상·착지 위치 이력·capture 보정·이전 IK 상태를 초기화한다.
2. Stop 전환은 마지막 최종 보정 명령에서 시작해 J2 정렬 기준 중립 자세로 돌아온다. 실시간 qpos/qvel을 변경하지 않는다.
3. 공용 커널이 동작을 종료했으면 이후 프리뷰 궤적으로 종료 목표를 덮어쓰지 않는다.
4. 기존 Stop 응답을 유지하면서 새 중립 자세의 완료 상태를 Stand로 표시한다.

첫 시작의 전진 궤적은 변경하지 않았다. 6초 전진→Stop 3초→6초 전진→Stop 3초 물리 시뮬레이션에서
두 Stop 모두 요청 후 1.48초에 완료됐고, 두 시작의 위상은 0이었다. 최종 토크는 ON이며
최종 보정 명령과 새 중립각 차이는 최대 0.032도였다. 이는 즉시 비상 토크 차단 시험이 아니다.

## 독립 물리 검증

`robustness_ground.py`는 기존 evaluator를 변경하거나 결과를 재활용하지 않고,
10초 대기→20초 전진→Stop 3초를 수행한다. 소스/설정 해시, 기본 목표·최종 명령·실제 관절각,
CAD 몸체 좌표 발 위치, 실제 지면 여유·접촉력을 별도로 기록한다.

아래는 시작 램프를 분리한 14.00~29.98초 통계다.

| 조건 | roll RMS / 최대 | pitch 최대 | 중간 스윙 접촉 FL/FR/RL/RR | 실제 속도 |
|---|---|---|---|---|
| 기본 | 1.327° / 3.680° | 3.139° | 3.13/6.25/0/0% | 0.04097m/s |
| 서보 명령 지연 60ms | 1.356° / 4.003° | 3.170° | 3.13/4.38/3.13/3.13% | 0.04103m/s |
| 모터 토크·무부하 속도 80% | 1.337° / 3.929° | 3.139° | 2.50/6.25/0/0% | 0.04106m/s |
| 두 조건 동시 | 1.357° / 4.010° | 3.164° | 3.13/5.00/3.13/3.13% | 0.04108m/s |

모든 조건에서 안전 정지/예외 없이 20초 전진하고 Stop 요청 후 1.48초에 Stand 복귀했다.
그러나 최대 roll/pitch 3도 기준은 모든 조건에서 미달했다. 모터 80%는 정해진 토크·속도
한계를 줄인 합성 조건이며, 실제 열화/전압/하중에서 측정한 서보 특성은 아니다.

시작 램프를 포함한 기본 10~30초에는 FR/RL의 계획상 중간 스윙 접촉이 각각 22.3%/17.1%다.
출발 직후 작은 진폭으로 지지하는 구간을 정상 속도 보행 통계와 섞어 숨기지 않는다.
발 중심의 세계좌표 이동은 쿠션 굴림을 포함하며 실제 접촉점 미끄러짐과 동일하지 않다.

## 회귀 검사

관련 CAD/지면 제어/발 배치/상태 전환 검사 **48개 통과**.
기존 자유 낙하 검사가 50스텝을 0.1초라고 가정하던 문제를 수정했다.
모델 timestep으로 0.1초에 해당하는 스텝 수를 계산하고 실제 경과시간으로 낙하량을 검증한다.
물리 모델은 이 테스트 수정에서 변경하지 않았다.

검증 수준: 기하·호스트 검사 및 추정 물리 모델 시뮬레이션이다.
설정 readback·실제 위치 유지·실물 전체 보행 시험은 수행하지 않았다.

결과 파일: `artifacts/audits/sway-2026-09-14/robustness-final-{nominal,delay60,motor80,combined}.json`,
`restart-final.json`. 접촉률만으로 이륙/착지 동기화를 판정하지 않으며, 후속 위상별 접촉 사건 분석이 필요하다.
