# V2: V1 기반 J1 고정 보행 실험 (2026-09-11)

상태: 구현·명목 조건 60초 전진 유지·추가 정지/물성 시험 완료. **정밀 수평/모든 품질 합격 기준은 미달**. 앱 표시 `(검증실패)` 유지. 실물 로봇 펌웨어는 변경하지 않았다.

## 변경을 분리한 순서

1. 보관 V1 재시험: 20초 무정지, 최대 roll 약5.05°로 기존 결과 재현.
2. J1 고정만 추가: 4.94초 tilt, 목표 IK 잔차27.3mm. 채택하지 않음.
3. 몸체 좌우 사전 이동만 제거: 여전히 tilt.
4. 기존 전신 보정용 위상별 사전 회전 보정 제거: 20초 무정지지만 뒷발 끌림 심함.
5. 지지 비율0.70→0.85: 뒷발 들림 개선. 들림40mm 후보는 44초에 tilt, 채택하지 않음.
6. 들림 목표40→25mm: 60초 측정 구간 동안 무정지. 최종 V2 선택.

다른 후보도 보존했다. 지지비율0.82는12.58초, 주기6.4초/들림40mm는50.94초에 tilt. 들림30mm는60초 무정지였으나25mm보다 최대 기울기와 추종 오차가 컸다. 몸체 높이 변화0mm 후보도 무정지였지만 평균 기울기가 더 커 최종 채택하지 않았다. 전체 비교 JSON은 `artifacts/upright/2026-09-11/cushion/v2-*.json`이다.

## 최종 프로필

- 이름: `cushion_support_shift_v2` / 앱: **V2 · J1 고정 · 실험**
- V1 보존: `cushion_support_shift_v1`. 실패한 센서 발걸음 제어기도 별도 보존.
- 주기4.8초, 지지비율85%, 보폭140mm, 들림 목표25mm, 높이 파라미터240mm.
- J1 목표는 기준 서기 각도로 유지. IK 안에서 J1 자유도를 제외하고 J2/J3만 계산한다. J1 실제 위치를 엔진에 강제로 지정하지 않는다.
- 좌우 사전 이동0, 기존 위상별 사전 회전0, 준비/착지 높이 변화최대10mm, 지연 IMU 잔여 보정은 J2/J3에 적용.
- 쿠션·CAD·모터 토크/속도·명령 지연·안전 정지 조건 유지. 접촉력 정답은 평가에만 사용.
- 실험은 추정 물성을 적용한 MuJoCo 강체 동역학이며, 실물 검증을 대체하지 않는다.
