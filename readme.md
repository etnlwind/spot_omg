# Spot OMG

Spot Micro 기반의 4족 보행 RL 로봇 프로젝트입니다.

## 🎯 목표

- STM32 펌웨어 개발
- Jetson Orin Nano 제어
- ROS2 연동
- Isaac Lab 강화학습 정책 적용
- Spot Micro 하드웨어 제작
