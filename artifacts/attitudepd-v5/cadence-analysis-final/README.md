# V5 전진 추진 30% 개선: 명령 궤적 분석

이 결과는 선택된 `forward_cadence_gain=1.3`의 공유 C 코드 계산이다. 실기 동작, 접지 시뮬레이션, 서보 추종 측정은 포함하지 않는다.

- 최대 전진 주기: V4 1.050초 → V5 0.80769초.
- 앞발 CAD 몸체 좌표계 밀기 평균 목표속도: 135.26 → 175.84mm/s(+30%).
- 후진 주기와 궤적은 V4와 동일하다.
- ±1.0·±0.588 입력, 앞발 추가 높이 0/30mm, 각 1,000위상에서 V4/V5 관절각과 CAD 발 위치가 정확히 일치했다.
- 16개 경우의 모든 샘플이 명목 관절 범위와 생산 코드 서보 변환 검사를 통과했다.

## 앞발 +30mm·최대 전진의 속도 제한 비교

12초의 50Hz 정상상태 명령에서 최고속도는 FR J3의 **281.25°/s**였다. 각도와 서보 틱으로 반올림하기 전 목표의 최고속도는 **276.06°/s**였다. 저장소 ServoProfile 모델대로 speed 3400을 ticks/s로 해석하면 **298.828°/s**이므로, 검사한 어느 20ms 구간도 해당 설정 속도를 넘지 않았다. 최고 양자화 명령 가속도는 **5053.71°/s²**였다.

이 비교는 실기 readback 또는 실제 속도 측정이 아니다. 3400은 관측된 설정값이며 하중 조건에서 보장된 속도가 아니다. J1/J3의 저장소 추정 무부하 정격은 270°/s로, 281.25°/s 명령은 그 추정값을 넘는다. 따라서 설정 속도 이하라는 결과만으로 추종 여유가 충분하다고 판단할 수 없다. 실제 모터 속도, 가속도 ramp, 하중, 전압과 통신 지연을 별도로 확인해야 한다.

한 틱의 차이는 20ms 간격에서 4.3945°/s, 연속 속도 차분에서는 219.7266°/s²에 해당한다. 보고서에는 반올림 전후 수치를 함께 기록했다. 시작·정지, IMU 보정, 접지 하중은 제외했다.

자세한 관절별 수치와 원본 SHA는 `summary.json`, 간단 비교는 `compact.csv`에 있다.
