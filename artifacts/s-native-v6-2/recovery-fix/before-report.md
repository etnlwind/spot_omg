# V6.2: 사진을 참고한 뒤쪽 밀기 확대

V6.1을 보존하고 `s_native_v6_2`를 별도 시뮬레이터 모델로 추가했다.
Windows/iOS 목록의 첫 모델이며 지원되는 시뮬레이터 연결의 기본값이다.
실제 로봇은 기존 V6.1 선택을 유지한다. 펌웨어 프로필 인덱스와 C 궤적,
보정값, 모터 방향은 변경하지 않았다.

## 사진과 각도의 해석

사용자 사진의 오른쪽으로 뻗은 뒷다리에서 **무릎 아래 부분이 바닥과 거의
수직이 되는 모양**을 목표로 삼았다. 사진의 투영 각도를 서보 각도로 복사하지 않았다.
사용자가 지적한 내딛기/뒤로 뻗기의 차이는 뒤로 밀 때 무릎을 펴고,
회수·앞쪽 착지에서는 더 굽히는 형태로 적용했다.

아래는 CAD 목표 궤적의 측면 계산이다. 아래 다리 선은 J3 무릎 축에서
쿠션 기준점으로 잇는 선이다. 실제 사진 속 로봇의 관절각 측정값은 아니다.

| 최대 전진 입력 기준 | V6.1 | V6.2 |
|---|---:|---:|
| S 대비 앞쪽 끝점 | +20mm | +20mm |
| S 대비 뒤쪽 끝점 | −65mm | −125mm |
| 뒤쪽 끝에서 아래 다리 선과 바닥의 각도 | 70.7° | 89.8° |
| 뒤쪽 끝의 J3 굽힘각 | 87.3° | 75.0° |
| 앞쪽 착지의 J3 굽힘각 | 93.6° | 93.6° |
| 최대 입력의 한 주기 | 1.2초 | 2.0초 |
| 보행 발 들기 목표 | 12mm | 12mm |

J3 굽힘각은 내디딜 때 커지고 뒤로 펼 때 작아진다. 링크 사이의 안쪽 각도는
반대 방향으로 변하며 V6.2 뒤쪽 끝에서 약 117.2°다. “무릎 안쪽 각도 90°”를
고정한 모델이 아니다. 실제 물리 재생에서는 뒷발 X가 약 −126.9mm까지 도달했다.
입력이 작으면 보폭도 작아지므로 125mm/89.8°는 최대 전진 입력의 목표다.

## 보존과 조정

- V6.1을 `V61_PROFILE`로 명시하고 새 `PROFILE`을 독립적으로 추가했다.
  STM32 내보내기/검증 도구는 계속 `V61_PROFILE`을 사용한다.
- S 출발, FR·RL 첫걸음, FR 첫걸음 추가 J1 오므림, 대각선 공통 상대 X/Z와
  타이밍, 두 걸음 정상 정지는 상속했다. 앞쪽 끝점을 더 앞으로 늘리지 않는다.
- 125mm를 기존 1.2초/1.6초 주기로 실행한 최대 전진 후보는 기울기 보호가
  작동해 채택하지 않았다. 2초 주기로 늘려 동작을 확인했다.
- 무제한 최대 후진 후보는 3.46초에 기울기 보호가 발생하고 넘어졌다.
  V6.2에만 후진 입력 60% 제한을 적용했고, `syncstate reverse_limit=600`으로
  보고한다. V6.1의 입력 범위는 그대로다.
- V6.2도 앞 J1 변환, 혼합 서보 속도·추종 지연이 반영된 물리 모터 모델을 쓴다.
  충돌, 기울기 보호와 센서 오류 처리는 끄지 않았다.

원본 소스와 해시는 `artifacts/s-native-v6-2/baseline-v61/`에 보관했다.
V6.1 C 커널/데이터, 펌웨어 프로필 배열과 공용 배포 JSON이 그대로임을
`preservation.json`으로 확인했고 기존 C/Python 일치 시험도 통과했다.

## 검증

- Windows 프로토콜, 기존 S-native, V6.1 C, V6.2 형상/물리, 앱 Stop 검사
  **96개 통과**. 두 생성 도구의 `--check` 통과. Windows 실행 파일 빌드 완료.
- 전진 47.3%/100%, 시작 0.3초/1.2초 후 정지, 후진 60%, 좌우 제자리 회전,
  전진+회전의 8조건 모두 보호 중단 없이 S 복귀. 목표 오차 0°,
  최종 실제 관절 오차 최대 0.991° 미만. 관측된 로봇 내부 충돌 프레임 0.
- 최대 전진 8초: 이동 X 약 1.118m, 방향 변화 −0.704°, 보행 최대 기울기 3.719°.
  정지 중 최대 기울기 5.789°.
- 최대 전진 30초: 이동 X 약 4.307m, 방향 변화 −0.756°,
  보행 최대 기울기 3.719°, 정지 중 4.463°. 보호 중단 없이 복귀.
- 후진 100% 명령을 보낸 제한 검증: 실제 요청이 60%로 제한되며 보호 중단 없이
  복귀. 후진 최대 기울기 7.907°, 방향 변화 +3.593°.

**한계:** 출발 1.2초 후 정지 조건의 최대 기울기는 10.861°로 보호 기준에
가깝다. 두 걸음 정지의 명령 타이밍과 실제 접지 동기 문제는 V6.1에서 상속했다.
이 모델은 추정 물성의 실험 모델이며 모든 입력 전환·지면·하중에 대한 안정성
검증이나 실제 로봇 보행 검증을 완료했다는 뜻은 아니다.
실기 업로드/설정 readback/위치 유지/전체 동작 시험은 수행하지 않았다.
iOS는 소스와 회귀 항목을 추가했으며 Xcode 빌드·기기 설치는 미실시다.
