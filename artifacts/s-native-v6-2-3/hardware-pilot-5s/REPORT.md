# V6.2.3/v65 실제 몸체 고정 5초 시험

전송 이미지 검증과 설치 readback 완료. 최고 서보 설정3400/254, 100% 직진 입력5초 뒤 정상 Stop(응답 elapsed7324ms). 최종 토크OFF, safetyOK, fault0.

367개 진단 샘플, 최저11.2V, lag70, lag+droop0, late0, derate권고. 256개 명령/256개 피드백 trace 검증. baldiag는20줄 뒤 타임아웃으로 불완전하다.

1.0~4.9초 구간의 관측값 비교(V622→V623):
- J2 관측 폭 약5.2~6.9° →11.0~11.5°. V623 뒤쪽 최대 J2 약60.1~60.6°.
- J3 최소 굽힘각 약88.6~89.5° →83.7~84.3°. 더 펴졌지만 명령 형상을 충분히 따라가지 못했다.
- 축별240ms 순차 조회와 서로 다른 주기로 극값/속도 비교에 aliasing이 있다. 실제 정확한 최고속도, 동시 발끝 위치 또는 바닥과90° 도달을 증명하지 않는다.

사용자가 여전히 뒤쪽 도달각이 부족하다고 확인했다. 이어 사진 기준이 아래 다리와 바닥 사이 거의90°임을 재강조했다. 관련 원래 기록은 docs/S-NATIVE-V62-2026-09-15.md. 임의의 뒤쪽 거리 확대 대신 실제 목표 도달을 다루는 V624 실험으로 전환했다.

후속12서보 조회 hw0, 11.2~11.4V,30~35°C. 개별 위치 유지 시험과 바닥 전체 보행은 하지 않았다.
