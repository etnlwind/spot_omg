# 22→23mm 스윙의 서보 지연·주기 분기 진단

## 결론

23mm 후보의2.4초 교대 진동은 내부 명령 필터 자체의 주기 분기가 아니다. 필터 출력은1.2초마다 거의 같지만 실제 관절과 몸체만2.4초로 갈라진다. J3의 비선형 목표 추종 지연이 커지는 것은 확인했으나, 고정 관절별 선행만으로 하중·접촉 동역학까지 해결한다고 볼 수 없다.

## 실행과 근거

기존 CSV에는 J2/J3 실제각과 내부 목표·속도가 없고23mm 후보는CSV를 저장하지 않았다. 따라서 `diagnose_arc_actuator_timing.py`로22mm/23mm를 각각25초 읽기 전용 계측 실행했다. 물리·제어 매개변수는 기존 후보 그대로며,500µs 물리 스텝마다 필터 속도·가속 요청과 토크 clipping을 관찰했다. 비교는5~25초, 주기 비교는15~25초다. 실제 로봇은 움직이지 않았다.

| 항목 |22mm 안정 후보|23mm 불안정 후보|
|---|---:|---:|
| 최대 roll |1.703°|5.682°|
| 내부 filtered각의1.2초 차이 RMS |대부분0°; 최대 약0.004°|대부분0°; 최대 약0.004°|
| 실제 관절각의1.2초 차이 RMS |0.030~0.089°|0.723~1.458°|
| 실제 관절각의2.4초 차이 RMS |0.001~0.004°|0.016~0.034°|
| 첫 roll2° 초과 |없음|5.26초|
| 첫 실제 토크 clipping |없음|7.70초|

따라서23mm에서는 실제 토크 포화보다 먼저 기울기 악화가 시작한다. 내부 필터의 반복 출력에 하중·관절·몸체·접촉 계통이 교대 응답한다. 필터 지연이 물리 안정성 경계를 옮길 수 있다는 가능성은 남지만, 명령 시계가 대각선마다 제멋대로 달라졌다는 근거는 없다.

내부 가속 제한은25rad/s²다. 물리 스텝의 가속 요청 clipping 비율은 J2 약74~100%, J3 약96~100%이며 두 후보가 거의 같다. 이는20ms마다 바뀌는 계단 목표를500µs 안에 따라가려는 내부 요청이 잘리는 비율이다. 모터가 실제 최고속도나 최고토크로 계속 동작한다는 의미가 아니다. 내부 목표 속도 최대는23mm에서 J3 약183°/s로 모터 한계270°/s보다 낮고, 실제 관절 속도도 그보다 낮다.

## 관절별 지연

5~25초 파형을1ms 보간하며 상수 위치 편향을 제거한 뒤 RMS가 최소인 시간차를 찾았다. 인과 전달함수 식별 결과가 아닌 파형 지연 대용값이다.

| 경로 / 축 |22mm|23mm|
|---|---:|---:|
| 명령→내부 filtered J2 |20~21ms|20~21ms|
| 명령→내부 filtered J3 FL/FR/RL/RR |26/30/32/29ms|28/39/31/32ms|
| 명령→실제 J2 FL/FR/RL/RR |46/42/45/41ms|45/45/44/41ms|
| 명령→실제 J3 FL/FR/RL/RR |39/64/63/40ms|49/73/65/48ms|

특히 FR-J3의 내부 파형 지연이30→39ms로 늘어난다. 최적 시간차를 빼도 내부 파형 RMS 차이는0.787→1.395°로 커지므로 단일 선행 시간만으로 설명되지 않는 모양 왜곡도 있다.

23mm FL을 낮은/높은 완전 스윙으로 나누면 낮은 스윙은 최고높이 평균6.10mm, 이륙 위상0.676, 이륙 때 roll−1.94°이고, 높은 스윙은24.66mm/0.619/+0.76°다. 그때 J2 명령→filtered 오차는0.840°/0.829°로 거의 같지만 filtered→실제 오차는1.615°/0.911°로 다르다. 동일한 예정 필터 위에 물리 기울기·하중·실제 추종 차이가 얹힌다.

## 의미 있는 actuator inverse의 범위

단순히 J2/J3가 서로 다른 발 위상을 쓰게 만들기보다, CAD에서 얻은 공통 시간의 `q_ref(t)`를 유지하고 내부 상태 `(filtered, target_velocity, delay_queue)`를 예측해 선행 명령 `u_j(t)`를 찾는 방식이 적절하다. 유한 구간의 반복 모형으로 출력 추종 오차·명령 변화량을 함께 줄이고 기존 관절/속도/가속/양자화 한계를 유지해야 한다. 불가능하면 명시적 실패로 남겨야 한다.

이것만으로 접촉 동역학 안정성이 보장되지는 않는다. 기존 dynamics_wbc는 QP 토크를 `q+(τ+Kd qdot)/Kp`로 위치에 바꾸면서 내부 필터·지연 때문에 최대20.46Nm의 예상 실행 차이가 남았고 추종·동기도 악화됐다. 같은 즉시 토크 역변환을 반복하면 안 된다. 새 어댑터는 내부 목표 추종을 별도 검증한 뒤 하중·수평·대각 접촉의 전체 물리 검증을 다시 받아야 한다.

## 산출물

`*-frames.json`에는20ms별 명령/지연/filtered/실제각·속도·토크·500µs별 clipping 집계를, `*-feet.csv`에는 발 접촉/높이를 저장했다. `analysis.json`은 주기 차이·지연·추종·포화 시점을 담는다.

```bash
/opt/anaconda3/envs/spot_omg/bin/python simulation/mujoco/scripts/analysis/diagnose_arc_actuator_timing.py
```

매개변수·제어기·plant 필터는 수정하지 않았고, 모든 참값은 평가에만 사용했다.

## 별도 발별 스윙 높이 어댑터

진단 후 개별 다리의 스윙 높이를 구분해 실험할 수 있도록 `arc_swing_shape.h` / `arc_swing_shape.py`를 새로 추가했다. 기존 실행 경로는 수정하지 않았다. 이 어댑터는 위 actuator inverse 구현이 아니라 **공통 위상을 유지하는 CAD 발 궤적 실험 도구**다.

입력 `delta4`는 FL/FR/RL/RR 순서의 높이차(m), 각±10mm 이내다. 같은 `target_phase`·`duty`·`motion_scale`·`offsets`를 사용하며, 스윙 정규화 위상u에 대해 `delta_i × motion_scale ×64u³(1−u)³`를 CAD Z에만 추가한다. 지지 중에는 원래 관절 목표를 그대로 보존한다. 영점·이륙·착지의 높이/1차/2차 미분이 연속인 목표 아치다.

모든 관절각은 CAD FK/IK로 얻는다. 기존관절 제한을 유지하며, 불가능한 목표나±10mm 초과를 자동 축소하지 않고 거부한다. 기본IK의0.1mm 종료 잔차가 작은 높이 보정에 계단을 만들지 않도록 이 별도 어댑터에서만 동일 CAD Jacobian으로 잔차를 추가 보정한다. 쿠션 메시·IK와 후단 서보 양자화의 수치 한계가 사라진다는 의미는 아니다.

```python
from arc_swing_shape import ArcSwingShape
shape = ArcSwingShape()
adjusted = shape.apply(target, frame, delta4)  # body-wave 적용 전 호출
```

12개 호스트 검사를 통과했다: 영점/정지진폭의 정확한 보존,8개 위상에서 지지각 불변·스윙XY 불변·요청Z 확인,±10mm 요청 완전 적용, C2 경계, 비유한 입력 거부와 실패 시 출력 불변. 목표 위치 오차 검사는11µm 허용치를 사용한다. 전체 보행의 물리 합격을 판정한 것은 아니다.
