# 녹화 영상의 발 끌림 구간

시간은 원본 10초 영상 기준이며 처음 2초 정지를 포함한다. 0.5배속 영상의 재생바에서는 2배 시각이고, 화면에 표시된 시뮬레이션 시간은 아래와 같다.

동일 물리 시뮬레이션을 재실행해 원본 영상 로그의 모든 관절각과 정확히 일치함을 확인했다(500개 시점, 최대 차이 0°). 쿠션 접촉점의 물질 속도로 바닥 상대 미끄러짐을 계산하므로, 미끄러지지 않는 굴림 접촉은 포함하지 않는다.

판정: 회수 위상 + 접촉력 1N 초과 + 접촉점 전방 미끄러짐 20mm/s 초과 + 몸체 기준 발의 전방 이동 20mm/s 초과. 로그 간격20ms, 영상 프레임 간격40ms다.
