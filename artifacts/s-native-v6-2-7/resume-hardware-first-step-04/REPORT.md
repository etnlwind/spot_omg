# V76 실기 출발 측정과 동일 목표 재생 비교

사용자 승인 후 실제 로봇에서 344/0 입력으로 짧은 출발 시험을 수행했다.
펌웨어/보행 정책 변경이나 OTA는 하지 않았다. 직전 전도는 이번 짧은 구간에서 재현되지 않았고
장치는 정상 정지를 보고했다. 시각 관찰/접촉 센서가 없어 끌림 없음 또는 안정 보행을 인증하지 않는다.

## 수집 조건 및 시행착오

- preflight: V76, V627, torque off, 11.2~11.4V, 12축 hw0.
- 01: 미지원 imudiag 조회에서 종료, 구동 없음.
- 02: 2초 host 타이머가 내부 Stand 준비 중 Stop을 보냄. elapsed0, 관절 기록0.
- 03: Stand를 먼저 확인했지만 drive 내부 준비가 다시 발생. 2초 입력은 정상 정지
  발 옮김만 기록(J1 목표 변화0). 보행 성공으로 해석하지 않는다.
- 04: 4초 host 입력 창으로 첫걸음 목표 확보. FR J1 목표 변화18.02° 확인.
  최초 started 응답부터 실제 커널까지 준비 약2초가 포함된다.
  정상 정지 elapsed4652ms는 정지 복귀를 포함한다. 순수 전진4초가 아니다.
- 232명령+464피드백을 페이지 내려받기/개수/매핑/순서 검증했다. 축별 조회 간격120ms.
- 최저10.9V, lag0, late1, 버스 재시도4/복구4/실패0. 추가 구동 중단.
- 최종 Stand, torque ON, error20틱(약1.76°), safety ok, fault0.

## 비교 방법

실제 목표 commands.csv를 전방 J1의 CAD 부호 변환 후 같은 순서로 추정 바닥 물리 모델에
20ms 격자로 재생했다. 실측 시각에 모델 관절각을 보간했다. 모델은 첫 목표에서1초 안정화,
개방전압11.3V를 가정했다. 실제 지지/마찰/초기 몸체 자세는 측정되지 않았다.
독립 제어기 비교나 서보 모델 식별이 아니라 **동일 목표에 대한 응답 비교**다.
수치 계산 RuntimeWarning이 있었으나 결과 배열/보고 값은 유한값이었다.

| 관절 | 실기 최대 목표 오차 ° | 모델 최대 목표 오차 ° | 모델-실측 RMS 차이 ° |
|---|---:|---:|---:|
|FL_J1|7.21|8.56|0.69|
|FL_J2|1.49|2.70|0.59|
|FL_J3|5.98|6.58|0.64|
|FR_J1|6.77|6.64|0.71|

이 짧은 기록에서 모델과 실측 RMS 차이는 축별 약0.59~1.49°다. FR J3 차이가 가장 크다.
J2의 최대 추종 오차는 오히려 모델이 실기보다 큰 축들이 있다. 모든 실기 지연이 모델보다
크다고 단정할 수 없다. 이전 전도에서 기록된 J3 약9~10°보다 이번 최대 약5~6°가 작지만
입력 지속시간/초기 자세/배터리/외부 지지를 통제한 A/B가 아니므로 개선으로 주장하지 않는다.

## IMU·온도 기록 한계

imu on의 Yaw/Roll/Pitch 스트림은 drive 실행 중 나오지 않았다. 따라서 처음부터 끝까지의
실측 IMU 시계열과 최대 기울기 비교는 확보하지 못했다. baldiag는 마지막32프레임 순환 기록이며
전송도20줄 후 prompt timeout이었다. 원본은 즉시 저장했다. Tilt snapshot none.
보행 전 roll -1.9°, pitch -0.5°, 이후 약 -2.0°/-0.2°는 최대 기울기가 아니다.
모델의 최대 기울기6.41°와 이 전후 값들을 직접 비교하지 않는다.

정지 후 ID12 온도85°C 표본이 나왔다. 구동 없이3회 재조회에서40/45/40°C였다.
간헐적 온도 이상 보고 문제는 남아 있고 실제 과열/센서 정상 어느 쪽도 단정하지 않는다.
원본 temperature-recheck.json 보존.

2. 내부 Stand 완료와 실제 첫 보행 프레임을 구분하는 시작 이벤트가 필요하다.
3. 전도 원인 확정에는 몸체/발 접촉 관측과 J1 첫걸음 전환 시점을 함께 비교해야 한다.
   이번 측정만으로 J3 또는 J1을 원인으로 확정하지 않는다.
