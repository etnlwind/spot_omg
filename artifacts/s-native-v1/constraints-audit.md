# 앞·뒤 다리 조건 감사

2026-09-14, `s_native_v1` 초기 실행본, 쿠션 포함2.754kg 모델, 전진60% 재현. 결과 원본은 constraints-audit.json, constraints-foot-frames.csv.

| 경로 | 앞·뒤 차이 | 이번 동작에서 영향 |
|---|---|---|
| 물리 J2 제한 | 앞−275~105°, 뒤−95~105° | 앞다리 수납용 확장. 보행실제약42~55°, 제한여유50°이상: 제한 충돌없음 |
| IK 제한 | 모든 다리 J1±30°, J2−45~100°, J3 0~150° | 공통 제한, 앞뒤 차등 클램프없음 |
| 서보방향 | 같은 쪽 앞뒤동일, 좌우반대 | 실기교정기준. 앞뒤방향뒤집음없음 |
| 센터틱 | 각모터실기교정값다름 | 인코딩후공통관절각으로복호화. 최대손실0.092° |
| 모터 | J2전체STS3250, J1/J3전체STS3215 | 앞뒤동일속도/토크/가속/지연/PD/마찰, 별도뒤다리감속없음 |
| CAD 축 | 실제CAD의미세한축차이존재 | 공통CAD IK로보상. 하드리밋도달없음 |
| 질량/관성 | 그룹질량앞뒤동일, 형상별중심/관성은CAD산출 | 총질량측정, 개별분포/관성은추정 |
| 쿠션 | 네발동일37.3×27mm/5g/마찰/접촉설정 | 앞뒤별축소/누락없음 |
| 충돌 | 같은생성규칙 | 측정400프레임활성접촉은floor↔각foot뿐. 다리간/몸통충돌없음 |
| 기존정책재배치 | s_native는통과하지않음 | `rebase_gait_on_s`즉시반환 |
| 기존보정 | 이전support_shift, position_wbc, pivot등설정없음 | 새모델경로에서실행안됨. 시험한실패보정은실행본에반영하지않음 |

관절추종RMS: 앞J2 1.08~1.13°, 뒤J2 1.17~1.38°. 앞J3 1.52~1.63°, 뒤J3 1.68~1.74°. 뒷다리만 멈추게 하는 큰 제한/명령손실은 확인되지 않았다.

실제 대각선발 높이차RMS는 몸체기준0.95/1.11mm, 바닥기준14.25/14.24mm. 따라서 현재확인된 주된 격차는 몸체회전과 접지동작에서발생한다. 고정/무부하 진단에서는0.01mm수준까지일치했다(이 진단은 실제보행검증을대체하지않음).

문제가 없다는 결론은 아니다. 초기 신모델은 몸체기준 동기만 검증하고 접지전환과 바닥기준 동기를 충족하지못했다. 이전기준이자동적용되어뒷다리만잘린다는가설은 이번데이터에서지지되지않았으며, 실제보행수정은별도로검증해야한다.
