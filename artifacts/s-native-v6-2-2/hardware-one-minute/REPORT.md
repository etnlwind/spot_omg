# V6.2.2 몸체 고정 1분 시험

사용자가 몸체 고정·발 공중 상태를 확인한 조건. 바닥 보행 시험이 아니다.

- 100% 입력 60초 뒤 정상 Stop. 정지 응답 62.901초는 복귀 시간을 포함한다.
- 최종 torque=off, safety=ok, fault_code=0.
- 3143개 진단 샘플, 최저 10.6V, lag=839, lag+droop=1, derate=recommended.
- 256개 명령/256개 피드백 시작 구간 trace를 페이지 단위로 검증해 보존했다. 전체 60초 관절 시계열은 아니다.
- 초기 약 5초의 J2 목표 폭 27.6~29.6°, 관측 폭 8.8~11.3°. J3 목표 폭 23.0~25.8°, 관측 폭 7.0~7.6°. 축별 240ms 순차 조회라 실제 극값과 동시 발 위치는 확정할 수 없다.
- 후속 12개 서보 상태 조회: hw=0, 11.2~11.4V, 30~35°C. 정지 상태 조회는 연속 동작 중 온도/전압의 극값을 보장하지 않는다.
- baldiag 응답은 21줄 뒤 타임아웃. 원문 transcript를 보존했으며 완전한 다운로드로 취급하지 않는다.

## 사용자 후속 기준

주기 0.5초 자체를 유지하는 것이 목적이 아니다. 현재 보이는 빠른 움직임을 유지하면서, 이전에 잘 움직이던 자세보다 실제 다리가 더 뒤로 뻗어야 한다. 주기는 늘어난 이동 거리를 수행하는 데 필요한 결과값으로 조정할 수 있다. 보낸 각도/명목 왕복 횟수만으로 충족했다고 보고하지 않는다.
