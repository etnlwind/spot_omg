# S 출발 · 뒤로 밀기 60mm V3

사용자가 요청한 것은 출발 자세나 앞쪽 내딛기를 늘리는 동작이 아니라, 지지 중 발을 뒤로 밀 때 더 멀리 뻗는 동작이다. S와 앞쪽 내딛기 +20mm를 유지하고, S 뒤쪽에만 부드럽게 추가 변위를 적용하여 끝 위치를 -20mm → -60mm로 늘렸다(최대 전진 입력). 전체 이동 범위는 40mm → 80mm다. 반대 입력에서는 진행 방향에 맞춰 좌우 동일하게 반전된다.

대각선 RL/FR 및 RR/FL의 목표 궤적과 반 주기 간격은 유지한다. 한쪽 대각선이 앞 극점일 때 다른 대각선은 뒤 극점에 도달한다. 앞뒤 거리가 비대칭이므로 두 극점의 절대 거리까지 같은 것은 아니다. 주기 0.8초, 교대 대기 0초, 명목 발 들기 25mm는 V2와 같다. V1/V2는 비교용으로 남겼다. 앱과 시뮬레이터에서 V3가 최신 기본 모델이다.

## 2초 정지 + 10초 보행 영상

`balance-video/four-views.mp4`는 같은 물리 재생을 앞/뒤/위/아래로 촬영한 12초 영상이다. 1280×840, 25fps, 300프레임. 전진 입력 100%, 넘어짐 허용 옵션을 사용했다. 아래 시점은 바닥만 렌더링에서 숨기며 물리 접촉은 그대로 계산한다. 개별 시점 영상도 같은 폴더에 보관한다.

- 영상 2.84초(보행 +0.84초): 롤 -5.4°, 피치 +2.9°로 흔들림 증가. FR/RL 접지 하중 8.1/12.2N, 함께 떠야 하는 FL/RR의 실제 높이는 5.9/38.2mm로 벌어진다.
- 영상 3.54초: 롤 +25.6°, FR 한 발에 약 21.4N이 걸린다.
- 영상 5.12초: 롤 약 45.7°로 크게 기운다.
- 영상 5.62초(보행 +3.62초): 롤 92.5°로 옆으로 넘어간다.

2.84초 표시는 롤/피치 절대값 5° 이상이 80ms 이어진 첫 지점을 재현 가능하게 고른 것이다. 이 수치가 모든 동적 보행의 균형 한계라는 뜻은 아니다. 5.62초 전도는 실제 재생 자세와 각도로 확인했다. 자세와 접지 하중은 `summary.json`과 `trajectory.json`에 기록했다.

관찰상 뒤로 미는 범위를 늘린 목표를 서보가 따라가는 동안 대각선 실제 발 높이가 벌어지고 지지가 한 발로 몰리며 몸체가 좌우로 흔들린다. 원인 분리 실험을 마친 것은 아니므로 특정 보정기 하나가 원인이라고 단정하지 않는다. 전도 후에는 다리가 목표를 크게 벗어나므로 전체 영상의 발 X 최댓값/최솟값을 정상 보폭으로 해석하지 않는다. 안정 보행 모델은 아니다.

관련 호스트 검사 48개와 맥 앱 빌드는 통과했다. 이는 목표 도달 가능성·버전 호환·대기 제거·기본 선택에 대한 확인이며 실제 물리 안정성 통과가 아니다. 실제 로봇은 구동하지 않았다.
